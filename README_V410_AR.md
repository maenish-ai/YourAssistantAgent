# YourAssistantAgent v4.1 — Direct GitHub Desktop overlay

هذه حزمة **كود مصدري جزئية قابلة للدمج** وليست Setup مكتملًا. الملفات مرتبة حسب مسارات المستودع.

## التثبيت بدون PowerShell
1. افتح GitHub Desktop ثم Repository > Show in Explorer.
2. خذ نسخة احتياطية من `launcher.py` (أو اعتمد على سجل Git للرجوع).
3. فك ZIP، وانسخ محتوياته إلى **جذر المشروع نفسه**، وافق على استبدال `launcher.py`.
4. في GitHub Desktop راجع Changed files، وتأكد أن التعديلات تشمل `launcher.py` وملفي `src/yaa_lite` والاختبار.
5. Commit ثم Push **بنفسك**؛ بعدها GitHub Actions يبني نسخة جديدة حسب إعدادات المشروع. نجاح البناء لا يثبت نجاح الواجهة على جهاز Windows.

## ما يعمل بالفعل في هذه الحزمة
- زر اختياري لاكتشاف أسماء البرامج من سجل Windows واختصارات Start Menu، وتخزين الفهرس محليًا؛ لا فحص عند بدء التشغيل.
- عند X: خلفية بأيقونة النظام أو خروج كامل أو إلغاء. يعتمد وضع الخلفية على وحدة Tray الموجودة أصلًا؛ إذا لم تتوفر، يبقى التطبيق مفتوحًا.
- مكتبة إضافية: معاينة خطة نسخ ملفات، نسخ احتياطي، محاولة تراجع عند الفشل، طابور مهمة واحدة، Git status للقراءة فقط. **هذه الأدوات البرمجية غير موصولة بتنفيذ أوامر الدردشة حتى الآن.**
- لا يوجد أي اتصال بعيد أو منفذ شبكة جديد.

## غير مكتمل — لا تفترض أنه متاح
- التحكم الفعلي العام بالماوس ولوحة المفاتيح، تشغيل جميع برامج Windows، تنفيذ مهام الدردشة تلقائيًا.
- واجهة PIN تربط التحقق بكل عملية كتابة؛ `SafeFilePlan.apply(authorized=True)` API للمطورين فقط ولا ينبغي عرضه كحماية PIN مكتملة.
- Git commit/push مؤتمت بموافقات، استعادة مهام بعد انقطاع الكهرباء، وصول عن بُعد آمن، سجل 30 يومًا، تعلم التفضيلات المربوط بالواجهة.
- اختبارات Windows الفعلية وقياسات RAM/CPU.

## السلامة
لا تستخدم SafeFilePlan على مجلدات فيها ملفات غير موثوقة أو يجري تعديلها بالتزامن؛ الفحص والنسخ الاحتياطي ليسا ضمانًا ضد سباقات الملفات. لا ترسل ملف الفهرس إلى الخدمات السحابية.
