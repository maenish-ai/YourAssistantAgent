# ملاحظات تطوير تجريبية

هذا ليس إصدار 6.0 نهائياً. الفرع مبني على `fce07d0`، ويحافظ على أرقام Android 1.8.10 وWindows التجريبية الحالية دون ادعاء تحديث إصدار المنتج.

- فصل إجراء Android عن Windows داخل GitHub Actions؛ يجب نجاح التنفيذ على GitHub قبل اعتبار الـ artifacts متاحة هناك.
- تقييد طلبات جسر المتصفح القادمة من مواقع عادية، وتحديد حجم الطلب ومهلة الاتصال. يجب إعادة تحميل الإضافة بعد التحديث. لا تزال هوية الإضافة غير مصادقة بشكل كامل.
- تثبيت نسخة نموذج الصوت والتحقق من بصمة الملفات التي يجري تنزيلها؛ تراخيص بيانات التدريب والملحقات تحتاج مراجعة إضافية.
- إعادة محاولة اتصال Relay بتأخير متدرج وحد أقصى، مع اختبارات محلية لإعادة الاتصال؛ الوصول من الإنترنت لم يثبت بعد.
- تحسين تتبع الملفات المرسلة من الهاتف أثناء تشغيل التطبيق والإبلاغ عن الخطوات التي فشلت، وعدم إخفاء ملاحظات الذاكرة خلف سجلات الأخطاء.

بناء Android المحلي debug لا يستخدم مفتاح توقيع نسخة المستخدم، وقد لا يثبت فوقها. اختبار الهاتف الحقيقي، وصوت العربية، وWindows، والاتصال من شبكة خارجية لم تنفذ في هذه البيئة. تفاصيل الاختبارات والحدود في `TEST_REPORT.md` و`SECURITY_AUDIT.md`.
