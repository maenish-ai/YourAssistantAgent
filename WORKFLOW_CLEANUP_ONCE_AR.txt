تنظيف GitHub Actions — مرة واحدة فقط
====================================

المشروع v1.4.1 يحتوي Workflow واحد فقط:
.github/workflows/build-windows.yml

لكن مستودع GitHub الحالي عندك ما زال يحتوي ملفاً قديماً من الإصدارات السابقة:
.github/workflows/windows-build.yml

رفع الملفات الجديدة فوق المستودع لا يحذف الملفات القديمة تلقائياً.
لذلك بعد رفع v1.4.1 احذف الملف القديم windows-build.yml مرة واحدة من GitHub.
بعدها سيبقى Workflow واحد فقط في الشريط الأيسر: Build Windows Setup.

سبب فشل v1.4.0 الذي تم إصلاحه:
كان الـWorkflow يستعمل /releases/latest من llama.cpp، بينما الإصدار stable الحالي لا يحتوي Windows CPU binary.
الإصدار الجديد يبحث في recent releases (بما فيها prerelease/build releases) عن llama-*-bin-win-cpu-x64.zip،
ومعه fallback ثابت إذا تغيّرت استجابة GitHub API.
