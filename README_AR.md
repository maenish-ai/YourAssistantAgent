# Your Assistant Agent v0.7.0 — Smart Agent

إصدار v0.7.0 يبني فوق v0.6.4 ويحوّل البرنامج من حملات ثابتة إلى وكيل ذكي قابل للجدولة والتحكم عن بُعد.

## أهم الإضافات

### Smart Agent
- تبويب جديد لإعطاء أوامر بالعربية أو الإنجليزية بصيغة طبيعية.
- يحوّل الأمر إلى خطة واضحة قبل الاعتماد.
- يدعم أكثر من قاعدة داخل نفس النص؛ مثال: الاثنين للفحيص والثلاثاء لدابوق.
- يدعم آخر بوست، البوست السابق، وترتيب سابق محدد.
- يدعم Rotation تلقائي للبوستات والعودة للبداية.
- يدعم جدولة يومية أو حسب أيام الأسبوع والساعة.
- يدعم فاصل زمني بين الجروبات بحد أدنى 30 ثانية.
- يمنع إعادة نفس البوست إلى نفس الجروب ضمن نافذة منع تكرار قابلة للتغيير.

### Facebook Groups
- إضافة زر لاكتشاف الجروبات الظاهرة للحساب المتصل وحفظها محليًا.
- الاستهداف حسب اسم الجروب أو الوسوم/المنطقة.
- الإدخال اليدوي للجروبات ما زال متاحًا.

### مشاركة بوست الصفحة من البروفايل الشخصي
- قواعد Smart Agent تستخدم مسار Facebook الأصلي: Share -> Share to a group.
- مصدر المحتوى هو صفحة Facebook التي تحددها، والتنفيذ يتم من الحساب الشخصي المتصل بالجلسة.
- إذا لم يعرض Facebook خيار المشاركة في مجموعة لذلك البوست، تسجل العملية كفشل بدل تنفيذ طريقة مختلفة بصمت.

### Telegram Remote
- Long Polling بدون Webhook أو سيرفر عام.
- Bot Token محمي بـ Windows DPAPI.
- يقبل الأوامر فقط من Telegram User ID المحدد.
- أوامر: `/status` و`/rules` و`/run ID` و`/pause` و`/resume` و`/stop`.
- يمكن كتابة أمر حملة طبيعي من الهاتف.
- إنشاء قاعدة جديدة وتشغيل Rule فوري وEmergency Stop تتطلب Approve/Cancel.

### Browser / Facebook Login
- يحتفظ باكتشاف المتصفحات واختيار Chrome / Edge / Chromium من v0.6.3.
- يحتفظ بتسجيل Facebook اليدوي والجلسة الدائمة من v0.6.4.
- لا يوجد CAPTCHA bypass أو stealth أو proxy rotation.
- عند ظهور Facebook Challenge / Checkpoint يتوقف الوكيل حتى تكمل التحقق يدويًا.

### Queue / Audit
- Smart Queue مستقل.
- Share History لمنع التكرار.
- Audit Log للأوامر الذكية، اكتشاف الجروبات، Telegram، والنتائج.
- Emergency Stop يلغي عناصر Facebook وSmart وWhatsApp المعلقة.

## طريقة تجربة v0.7.0

1. من Dashboard تأكد أن الحالة تعرض Facebook Connected.
2. من «مجموعات فيسبوك» اضغط «اكتشاف مجموعاتي من فيسبوك» أو أضف جروب اختبار يدويًا.
3. افتح «الوكيل الذكي» وضع رابط صفحة المصدر مرة واحدة.
4. اكتب أمرًا مثل:
   - `كل يوم الاثنين الساعة 8 مساء خذ آخر بوست وشاركه على الجروبات اللي اسمها يحتوي الفحيص، كل نص دقيقة.`
   - `يوم الاثنين الساعة 8 مساء آخر بوست للفحيص. يوم الثلاثاء الساعة 6 مساء البوست اللي قبله لدابوق.`
5. اضغط Preview وتأكد مما فهمه الوكيل.
6. اضغط Approve لحفظ القاعدة/القواعد.
7. ابدأ أول تجربة بجروب اختبار واحد قبل توسيع العدد.
