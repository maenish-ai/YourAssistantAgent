Your Assistant Agent v2.9 — النسخة الخفيفة والآمنة عند الخمول
=============================================================

مهم: أغلق النسخة القديمة إغلاقًا كاملًا، واحتفظ بنسخة احتياطية من ملفات مشروعك.
لا تشغّل النسخة القديمة على الجهاز الذي تجمّد بسببها.

طريقة الرفع على GitHub:
1. فك ضغط هذه الحزمة على جهازك.
2. انسخ المحتويات على مجلد المصدر الكامل للمشروع، مع دمج المجلدات.
3. لا تمسح الملفات التي لم تتضمنها الحزمة. لا ترفع .env أو أي API Key.
4. افتح GitHub Desktop؛ راجع التغييرات ثم Commit وPush إلى main.
5. افتح Actions → Build Windows Setup وانتظر نجاح البناء.
6. حمّل أداة التثبيت الجديدة من Artifacts. بعد التثبيت لا تشغّل التطبيق تلقائيًا؛ خيار التشغيل غير محدد مسبقًا.

السلوك الافتراضي بعد التحديث:
- زر X يغلق البرنامج بالكامل.
- التشغيل التلقائي مع Windows متوقف ويُحذف مدخل Run الخاص بهذا التطبيق.
- فحص Facebook التلقائي والنسخ الاحتياطي التلقائي والجدولة الخلفية متوقفة.
- المهام القديمة لا تُحذف! لتفعيل تنفيذها المجدول، افتح Tasks ووافق على تفعيل «جدولة الخلفية».
- المحادثة عبر Groq والصوت والموافقات والميزات اليدوية تبقى متاحة عند الطلب.

اختبار حذر للكمبيوتر:
1. تأكد ألا يبدأ المساعد تلقائيًا بعد إعادة تشغيل Windows.
2. أغلق البرامج الثقيلة الأخرى واحفظ عملك قبل تشغيل المساعد الجديد لأول مرة.
3. افتح Task Manager على تبويب Processes قبل تشغيل المساعد ثم شغّل المساعد يدويًا.
4. اتركه دقيقة إلى دقيقتين بدون أوامر، وراقب CPU وMemory وDisk.
5. إذا ارتفعت الموارد بشكل غير طبيعي أو عاد التجمّد، أغلقه فورًا من X، ولا تستخدمه حتى نجمع تقريرًا.
6. جرب رسالة نصية واحدة أولًا؛ الصوت بعد نجاح قياس الخمول.

هذه الحزمة تحديث لملفات المصدر وليست Setup.exe؛ البناء النهائي يحدث على GitHub Actions.
لا توجد أي إضافة مدفوعة أو موديلات صوت محلية كبيرة.
