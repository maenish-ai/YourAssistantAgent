- Added persistent chat history and conversation context.

- Added backup restore with app restart and local rescue DB.

- Kept Dual Local AI, Facebook Pending Approval semantics, Telegram, GitHub Deployment, Wake/Sleep and WhatsApp features.
- Added cryptography dependency and backup/chat tests.
