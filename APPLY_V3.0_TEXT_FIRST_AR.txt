Your Assistant Agent 3.0.0 — واجهة حديثة + إملاء صوتي إلى نص فقط
=====================================================

1) أغلق البرنامج القديم تمامًا من أيقونة Windows بجانب الساعة > Exit.
2) احتفظ بنسخة احتياطية من مجلد المشروع وبياناتك قبل الاستبدال.
3) فك هذا ZIP في مجلد مؤقت.
4) انسخ الملفات والمجلدات (بما فيها .github) إلى مجلد مصدر المشروع الموجود عندك:
   C:\Users\Maen\Desktop\YourAssistantAgent
   اختر Merge / Replace للملفات المتشابهة.
5) لا تغير ملف .env ولا ترفعه إلى GitHub، ولا تشارك أي كلمة مرور أو مفتاح API.
6) افتح GitHub Desktop > راجع التغييرات > Commit > Push إلى المستودع الخاص بك.
7) افتح صفحة GitHub Actions: Build Windows Setup. لا تثبت حتى ينجح البناء.
8) بعد تثبيت v3.0 اختبر رسالة نصية قصيرة أولاً، ثم جرّب زر «إملاء نص».
   النص يتكوّن بعد كل جملة/وقفة قصيرة. راجعه ثم اضغط «إرسال» بنفسك.
9) لتحديد المايكروفون: Settings > الإملاء إلى نص > الميكروفون.
10) زر X يغلق التطبيق. تشغيل الخلفية والنسخ الاحتياطي التلقائي لا يُفعّلان افتراضيًا.

تذكير: هذا تحديث ملفات مصدر، وليس APK أو Windows Setup جاهزًا.
لا يوجد أي اشتراك جديد أو بطاقة مطلوبة. يحتاج فهم الصوت إلى Groq API مجاني
ضمن الحدود المتاحة؛ والمحادثة والميكروفون لم يُختبرا فعليًا على جهازك بعد.
