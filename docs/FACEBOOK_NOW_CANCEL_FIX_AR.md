# إصلاح النشر الفوري وإلغاء المهام — نسخة تطوير

هذا التعديل يخص برنامج Windows ومساعد الهاتف. لا يحذف قواعد Facebook المحفوظة ولا ينشر شيئاً عند تثبيته.

- عندما يطلب المستخدم النشر الآن بوضوح، لا يرث المخطط تلقائياً وقتاً أعاده النموذج من طلب سابق. تُعرض معاينة جديدة للمصدر والمنشورات والمجموعات ويظل التنفيذ محتاجاً زر الموافقة.
- لا يختار البرنامج مهمة محفوظة مقترحة من النموذج إلا إذا ذكر المستخدم رقمها المطابق. لا تستخدم صفحة افتراضية قديمة بصمت في طلب النشر الفوري عندما لم يحدد النموذج المصدر. إذا لم تتضح كلمة ترشيح المجموعات، يطلب توضيحاً بدلاً من افتراض النشر على الجميع.
- طلب الإلغاء الطبيعي يلغي معاينة معلقة فقط، ويصرح أن الجدول المحفوظ أو النشر الجاري لم يتوقف تلقائياً.
- من محادثة Android: `/tasks` لعرض المهام المحفوظة؛ `/pause_task 12` لتعطيل جدول المهمة رقم 12 فقط (الرقم مثال، استخدم الرقم الحقيقي)؛ `/stop_facebook` لطلب إيقاف مهمة Facebook الجارية. الإيقاف لا يتراجع عن مشاركة تمت فعلاً، وقد تنتهي خطوة كانت جارية. تعطيل الجدول لا يضمن إيقاف مهمة بدأت أو وُضعت في التنفيذ قبل التعطيل.

قبل التحديث، إذا كنت قلقاً من مهام قديمة على جهازك، افتح صفحة «المهام» في Windows وراجع حالة كل مهمة وعطّل الجدول غير المرغوب، وأوقف أي تشغيل جارٍ إن وجد. لا يمكن لهذه الحزمة معرفة حالة جهازك أو تغييرها تلقائياً. بعد بناء نسخة Windows وتثبيتها، اختبر باستخدام حساب/بيئة مصرح بها ولا تعتمد على الاختبارات الآلية وحدها. قد لا يطابق الفهم الآلي كل صيغ اللهجات؛ راجع الصفحة والمنشورات والمجموعات والموعد في المعاينة قبل الموافقة.

الاختبارات المحلية على Linux: `PYTHONPATH=src python -m pytest -q tests --import-mode=importlib` → 516 نجح، 8 متجاوزة، وتحذير واحد. لم يُختبر Windows أو حساب Facebook حقيقي أو النشر الفعلي في هذه البيئة.
