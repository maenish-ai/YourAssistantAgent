Your Assistant Agent v4.2.0 - GitHub Desktop overlay

انسخ محتويات ZIP إلى جذر مستودع YourAssistantAgent (مع الحفاظ على المجلدات)، ثم Commit وPush من GitHub Desktop.
لا تشغل سكربت PowerShell. هذه ملفات مصدر وليست Setup.

ما تم:
- زر إضافة ملفات متعدد، عرض أسماء الملفات، مسحها ومعاينة محلية.
- قبول أنواع شائعة: ZIP وPDF وOffice والصور والفيديو والملفات النصية (القبول لا يعني فهم محتواها).
- فحص ZIP للبيانات الوصفية فقط، وقراءة نصوص صغيرة محلياً؛ لا فك ضغط ولا تنفيذ.
- اقتراح مستودع maenish-ai/YourAssistantAgent عند وجود قرائن واضحة بالاسم أو بنية ZIP، وليس ربطاً تلقائياً.
- قبل إرسال المعاينة إلى Groq، يظهر طلب موافقة. الملفات الفعلية لا تُرفع إلى Groq.
- لا Commit ولا Push تلقائي؛ GitHub Desktop يتولى الرفع بعد مراجعة المستخدم.
- الاحتفاظ بتعديلات v4.1 السابقة: اكتشاف برامج Windows وخيارات الخروج.

حدود مهمة:
- لا يتم فهم محتوى PDF أو Office أو الصور أو الفيديو بعد؛ المرفقات من هذه الأنواع تعرض بيانات وصفية فقط.
- زر الإرفاق الأصلي موجود في v3.0، وهذه النسخة تضيف واجهة أوضح وتلخيصاً آمناً.
- لا يوجد دمج تلقائي لمحتويات ZIP داخل المستودع؛ هذا يتطلب محرك مراجعة/موافقات مستقل.
- يجب اختبار واجهة Tk على Windows وبناء GitHub Actions قبل اعتبار النسخة جاهزة للإنتاج.
