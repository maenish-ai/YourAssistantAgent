Your Assistant Agent v0.7.0 — SMART AGENT PATCH ONLY
=====================================================

هذه الحزمة مصممة لتوضع فوق مستودع GitHub الحالي الذي وصل إلى v0.6.4.
انسخ الملفات مع Replace ثم Commit + Push. الـGitHub Workflow الحالي سيبني Windows Setup فقط.

أهم ما أضيف في v0.7.0:

1) Smart Agent
- تبويب جديد «الوكيل الذكي».
- تكتب أمر الحملة بالعربية أو الإنجليزية بصيغة طبيعية.
- معاينة ما فهمه الوكيل قبل الحفظ.
- اعتماد القاعدة مرة واحدة ثم تنفيذها حسب الجدول.
- أمثلة مفهومة:
  * كل يوم الاثنين الساعة 8 مساء خذ آخر بوست وشاركه على الجروبات اللي اسمها يحتوي الفحيص كل نص دقيقة.
  * الثلاثاء الساعة 6 مساء خذ البوست اللي قبله وشاركه على الجروبات اللي فيها دابوق.
  * كل يوم الساعة 7 مساء دوّر البوستات وارجع من الأول عند نهاية القائمة.

2) اختيار البوستات وتدويرها
- Latest post.
- Previous post / offsets.
- Rotation تلقائي للبوستات مع حفظ موضع الدوران.

3) منع التكرار
- Share History مستقل.
- قبل إدخال نفس البوست إلى نفس الجروب، يفحص نافذة منع التكرار.
- الافتراضي 14 يومًا ويمكن تغييره من الإعدادات الداخلية/الأوامر.

4) الجروبات
- زر «اكتشاف مجموعاتي من فيسبوك».
- يقرأ الجروبات الظاهرة للحساب المتصل ويحفظ الاسم والرابط محليًا.
- يبقى الإدخال اليدوي موجودًا كخيار احتياطي.
- الاستهداف يدعم الاسم والوسوم/المنطقة مثل الفحيص أو دابوق أو صويلح.

5) Native Facebook Share
- القواعد الذكية تستخدم Share -> Share to a group من البوست الأصلي بالحساب الشخصي المتصل.
- إذا لم يوفر Facebook مشاركة أصلية لهذا البوست، العملية تفشل بوضوح ولا تتحول بصمت إلى طريقة أخرى.
- الحملات القديمة بقيت كما كانت للحفاظ على التوافق.
- لا يوجد CAPTCHA bypass أو stealth أو proxy rotation. عند Checkpoint يتوقف الوكيل.

6) Telegram Remote
- Long Polling، لذلك لا يحتاج Webhook أو سيرفر عام.
- Bot Token يُحفظ باستخدام Windows DPAPI.
- يقبل الأوامر فقط من Telegram User ID الذي تحدده.
- /status /rules /run ID /pause /resume /stop
- يمكن كتابة أمر حملة طبيعي من الهاتف.
- إنشاء قاعدة جديدة، Run Now، وEmergency Stop تحتاج Approve/Cancel من داخل Telegram.

7) Queue / Audit
- Smart Queue منفصل عن الحملات القديمة وواتساب.
- حالات done / failed / blocked / cancelled.
- سجل كامل لأحداث القواعد الذكية واكتشاف الجروبات وتيليجرام.

8) الأمان والتحديث
- يحتفظ بتسجيل Facebook اليدوي من v0.6.4 وبالـProfile الدائم.
- يحتفظ باختيار Chrome/Edge والمتصفحات المكتشفة.
- Setup محدث إلى v0.7.0 ويغلق النسخة القديمة وشجرة عملياتها أثناء التحديث مثل الإصدار السابق.

ملاحظات مهمة للتجربة الأولى:
- قبل Smart Agent: تأكد أن Dashboard يعرض Facebook Connected.
- من «مجموعات فيسبوك» استخدم «اكتشاف مجموعاتي من فيسبوك» أو أضف جروب اختبار يدويًا.
- في «الوكيل الذكي» ضع رابط صفحة المصدر مرة واحدة.
- استخدم Preview أولًا وتأكد من الوقت والكلمة المستهدفة والبوست قبل Approve.
- ابدأ بقاعدة واحدة وجروب اختبار واحد للتأكد من واجهة Facebook الحالية عندك؛ Facebook قد يغير عناصر الواجهة من وقت لآخر.
