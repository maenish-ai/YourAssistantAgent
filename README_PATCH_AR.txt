Your Assistant Agent v0.6.3 — PATCH ONLY

هذا الملف يحتوي فقط على الملفات المطلوبة للتحديث، وليس المشروع كاملًا.

انسخ محتويات هذا الـ ZIP فوق مشروع GitHub الحالي مع Replace مع الحفاظ على نفس المجلدات.

التعديلات المضمنة:
1) اكتشاف المتصفحات المثبتة على Windows تلقائيًا.
2) قراءة المتصفحات المسجلة في Windows Registry بالإضافة للمسارات الشائعة.
3) عرض المتصفحات للمستخدم قبل أول فتح لفيسبوك.
4) حفظ المتصفح المختار وإعادة استخدامه لاحقًا.
5) إمكانية تغيير المتصفح من Settings.
6) دعم أساسي كامل لـ Google Chrome وMicrosoft Edge وChromium.
7) إظهار Brave/Vivaldi/Opera والمتصفحات الشبيهة كدعم تجريبي/محدود.
8) اكتشاف Firefox مع توضيح أنه غير مدعوم بمحرك الأتمتة الحالي.
9) إبقاء Bundled Chromium كخيار احتياطي.
10) Profile فيسبوك الدائم يبقى منفصلًا عن Profile المتصفح الشخصي.
11) إذا فشل فتح المتصفح المختار تظهر حالة خطأ واضحة في Dashboard وفي Audit Log.
12) عند Facebook Challenge/CAPTCHA يتوقف الوكيل ولا يحاول تجاوزه.
13) Setup يحافظ على تعديل v0.6.2: إغلاق النسخة القديمة وشجرة عملياتها التابعة تلقائيًا بعد موافقة المستخدم.
14) GitHub Workflow ينتج Setup فقط بدون Portable.
15) الإصدار الجديد: 0.6.3.

طريقة الرفع:
- فك ضغط هذا الملف.
- انسخ الملفات فوق مشروعك الحالي.
- وافق على Replace.
- تأكد أن مجلد .github انتقل أيضًا لأنه مخفي.
- Commit ثم Push في GitHub Desktop.
- GitHub Actions سيبني فقط YourAssistantAgent-Windows-Setup.

ملاحظة:
Telegram Remote غير موجود في هذا Patch لأنه لم يتم اعتماده نهائيًا ضمن التعديلات الحالية.
