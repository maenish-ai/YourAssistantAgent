# Windows 5.2.0 — أدوات تحكم عامة

أسماء المواقع والصفحات والمستودعات التي يذكرها صاحب البرنامج كأمثلة لا تحصر وظائف المساعد. هذا التحديث يوسع أدوات الكمبيوتر العامة التي يختار منها حسب الطلب والموارد الموجودة فعلياً، بدلاً من إضافة وصفة لكل اسم.

## الأدوات الجديدة

- اكتشاف برامج Windows من اختصارات قائمة ابدأ والبحث بأسمائها. يفتح المساعد معرّفاً مرصوداً فعلياً ويقرأ النافذة بعد طلب التشغيل. إذا تعددت البرامج المطابقة يسأل عن المقصود؛ لا يخترع اسم ملف تنفيذي.
- فتح أي رابط HTTP/HTTPS مطلوب، أو نطاق صالح مكتوب صراحةً، بما فيه الأسماء الدولية. الاسم المبهم يبقى بحثاً فعلياً عن الاسم، ولا يتحول إلى عنوان مخترع. البحث العام لا يحتاج أن يكون الموقع ضمن قائمة أسماء ثابتة.
- فتح المجلدات في مستكشف الملفات، وإنشاء مجلدات جديدة، ونسخ الملفات أو نقلها أو إعادة تسميتها، وفك ZIP في مجلد جديد. تستخدم الأدوات المسارات الموجودة في قائمة الملفات والصلاحيات المضبوطة للكمبيوتر، وتعيد المسار الفعلي بعد التنفيذ.
- هذه الأدوات متاحة للتخطيط داخل المهمة التي وافقت عليها من الهاتف، إلى جانب أدوات النوافذ والتبويبات والنقر والكتابة والتحكم اليدوي الحالية. العمليات لا تكتب فوق ملف موجود؛ الاسم المتعارض يحتاج اختيار اسم آخر. فك ZIP لا يشغّل محتوياته.

التعامل مع فيسبوك والمستودعات ما زال يستخدم أدواته المتخصصة عند طلب تلك العمليات، بينما المهام العامة تستخدم أدوات الكمبيوتر. مجلد يحمل اسماً مثل «مجموعات» لا يُعامل تلقائياً كمهمة فيسبوك.

## التثبيت

1. فك `YourAssistantAgent-v5.2.0-source.zip` وارفع محتوياته إلى جذر مستودعك، مع `.github`، ثم اعمل Commit وPush.
2. شغّل **Build Windows Setup** من GitHub Actions ونزّل **YourAssistantAgent-Windows-Setup-v5.2.0** وثبّت EXE. الحزمة المحلية تحتوي المصدر، ولا تحتوي EXE مبنياً على Windows.
3. **Android 1.7.0 لم يتغير في هذا التحديث**، ويستخدم الأدوات الجديدة عبر نسخة الكمبيوتر. إذا ثبتّه بالفعل، لا تحتاج إعادة تثبيته أو إعادة الاقتران. نسختا Release وDebug المطابقتان للتوقيع السابق موجودتان بالحزمة عند الحاجة.
4. أغلق نسخة الكمبيوتر القديمة وافتح الجديدة؛ تحقق من Windows **5.2.0** في **إعدادات الربط ← تشخيص الاتصال** على الهاتف.

تفاصيل QR العمودي ومسارات فيسبوك وZIP والمستودع موجودة في [دليل 5.1](README_V510_AR.md).

## حدود واضحة

اكتشاف البرامج يغطي اختصارات قائمة ابدأ، وليس كل حزمة UWP أو برنامج بلا اختصار. يمكن التعامل مع النوافذ الموجودة عبر أدوات الكمبيوتر الأخرى. أدوات النسخ والنقل الحالية تعمل على الملفات؛ إدارة مجلد كامل عبر هذه الأدوات تحتاج ZIP أو واجهة مستكشف الملفات. لا توجد أداة لحذف ملفات موجودة تلقائياً.

النموذج لا يرى أو يتحكم بصورة مطلقة في كل تطبيق. قراءة الواجهة تعتمد على دعم التطبيق لإمكانية الوصول؛ التحكم اليدوي من الهاتف متاح داخل جلسة Windows المسموح بها. كلمات المرور والتحقق وحوارات Windows المحمية لا يجري تجاوزها. أسماء الأمثلة ليست أهدافاً فعلية أو تفويضاً للنشر.

الاستضافة المباشرة من الكمبيوتر وشروط الاتصال الخارجي لم تتغير: يلزم مسار HTTPS قابل للوصول من شبكة الهاتف، ولا يكفي QR لتجاوز CGNAT. المحادثة والتخطيط ما زالا يستخدمان Groq حسب الاختيار السابق.

التقرير المرفق يسجل الاختبارات الفعلية. الاختبارات تستخدم ملفات مؤقتة وحدود Windows مضبوطة؛ لا تعتبر تجربة حقيقية على جهاز صاحب البرنامج أو حساباته.
