# Your Assistant Agent v1.0.0 — Employee Mode

هذا الإصدار يحوّل Smart Agent من محلل أوامر قائم أساسًا على الصيغ إلى وضع هجين: **AI Brain + Safe Local Parser**.

## 1) عقل الوكيل الذكي

- يدعم العربية العامية الأردنية/الشامية، العربية الفصحى، الإنجليزية، والكلام المختلط.
- يفهم المقصود من الكلمات المتغيرة بدل برمجة أسماء مناطق ثابتة. مثل: خلدة، ماحص، صويلح، دابوق، أو أي اسم آخر يرد داخل شرط اسم الجروب.
- يدعم أسلوب المحادثة والمتابعة: بعد معاينة خطة تستطيع قول "خليها الساعة 9" أو الرد على سؤال توضيحي قصير.
- إذا كان الهدف أو الوقت أو البوست غير واضح، يسأل سؤالًا واحدًا بدل أن يخمّن أو يوسع التنفيذ إلى كل الجروبات.
- يعرض Preview قبل الحفظ مع الهدف وعدد الجروبات المطابقة وأمثلة منها.
- نفس AI Brain يستخدمه Telegram Remote للأوامر الطبيعية.

### تفعيل Employee Mode

من تبويب **Smart Agent > عقل الوكيل الذكي**:
1. فعّل `استخدام AI Brain`.
2. اترك النموذج الافتراضي `gpt-6-luna` أو اكتب نموذج OpenAI متاحًا لحسابك.
3. ألصق OpenAI API Key.
4. اضغط حفظ ثم اختبار.

يتم تخزين المفتاح محميًا عبر Windows DPAPI. عند تفعيل AI Brain، يتم إرسال نص أمر الحملة وسياق المحادثة القصير إلى OpenAI API لفهم القصد. إذا تعذر AI، يرجع البرنامج إلى الفهم المحلي الآمن ولا يحول فلترة غير واضحة إلى كل الجروبات.

## 2) الجروبات التي تحتاج موافقة أدمن

بعد الضغط على Share/Post توجد ثلاث حالات نجاح:
- `Published`: Facebook أكد النشر.
- `Submitted`: Facebook استلم عملية المشاركة لكن لم يعرض حالة ظهور مؤكدة.
- `Pending Approval`: Facebook أظهر أن المنشور بانتظار موافقة الأدمن/المشرف.

`Pending Approval` و`Submitted` **ليستا Failed**، ويتم حفظهما في Share History حتى لا يعيد الوكيل إرسال نفس المنشور إلى نفس الجروب خلال نافذة منع التكرار.

## 3) ما بقي من النسخ السابقة

- Facebook group discovery.
- Native Share -> Share to a group.
- Smart Queue + no-repeat.
- Edit / Delete / Cancel Pending للقواعد.
- Telegram Remote.
- Wake/Sleep وWakeToRun.
- GitHub Deployment من داخل البرنامج.
- Windows Setup فقط في GitHub Actions.
