# نقل ملف واسترجاعه من الهاتف

لملف واحد داخل منطقة الملفات التي اخترتها في Windows، أرسل من المحادثة مساراً نسبياً مثل `/trash reports/file.txt` أو `احذف الملف reports/file.txt`. سيعرض التطبيق المسار الكامل والحجم ويطلب موافقة قبل النقل. يمكن إلغاء المعاينة دون تغيير الملف. لا يدعم هذا الأمر حذف المجلدات أو التخمين عند غموض الاسم.

بعد الموافقة ينقل البرنامج الملف إلى مجلد `.yaa-recovery` بجانب موقعه الأصلي، ويعرض مسار الاسترداد. هذا المجلد **ليس سلة محذوفات Windows** ولا يجري إفراغه تلقائياً؛ يبقى الملف شاغلاً مساحة التخزين. لاستعادته أرسل `/restore` ثم مسار الاسترداد الظاهر في النتيجة ووافق على المعاينة. لا يستبدل الاسترجاع ملفاً موجوداً في الوجهة.

قبل النقل يعيد البرنامج فحص بيانات الملف الأساسية مثل الحجم ووقت التعديل وهوية الملف. ذلك يقلل احتمال استخدام معاينة قديمة لكنه ليس ضماناً كاملاً ضد التغييرات المتزامنة. إذا تعذر إنشاء مجلد الاسترداد أو كان الملف خارج المنطقة المسموح بها، يفشل الطلب ولا يتحول إلى حذف دائم.

هذا تحديث لبرنامج Windows؛ يلزم بناء نسخة جديدة وتثبيتها. اختبر أولاً بملف تجريبي على جهازك. لم يُختبر هذا المسار على Windows فعلي في بيئة التطوير، ولا يضمن فهم كل صيغة عامية أو مسار مطلق.

التحقق المحلي على Linux: نجح 522 اختبار Python شاملًا، وتُجاوزت 8 اختبارات؛ وبعد إضافة اختبار رابط مجلد الاسترداد الرمزي نجحت 63 حالة مرتبطة بالملفات والخدمة. لم يُنتج EXE أو يُختبر النقل على Windows فعلي في هذه البيئة.
