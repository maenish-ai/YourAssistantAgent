# YourAssistantAgent v4.3 — رفع ZIP فعلي إلى GitHub

هذا التحديث يضيف إلى واجهة المحادثة زر **⬆ ZIP → GitHub**، ويدعم رسالة مثل: «ارفع ملف ZIP إلى GitHub».

## التركيب

1. افتح مستودع `maenish-ai/YourAssistantAgent` في GitHub Desktop (أو اعمل Clone إذا لم يكن موجوداً على الكمبيوتر).
2. انسخ **محتويات** حزمة التعديل إلى جذر المستودع المحلي مع الحفاظ على مسارات المجلدات، واستبدل `launcher.py` فقط عند الطلب.
3. راجع الملفات في GitHub Desktop، ثم Commit وPush إلى فرع `main` لتشغيل بناء Windows الموجود في `.github/workflows/build-windows.yml`، أو شغّله يدوياً عبر `workflow_dispatch` عند العمل على فرع آخر.
4. بعد بناء النسخة وتشغيلها على Windows، افتح المحادثة وارفق ZIP، ثم اضغط «ZIP → GitHub» أو اكتب طلب الرفع.
5. اختر مجلد نسخة Git المحلية الصحيحة؛ ستظهر معاينة بالملفات الجديدة والمعدلة والفرع الذي سيُدفع إليه. **لا يحدث أي تعديل إلا إذا ضغطت Yes على نافذة الموافقة.**
6. يستخدم البرنامج Git الموجود في الجهاز لإجراء Commit ثم Push. تسجيل الدخول إلى GitHub Desktop وحده لا يضمن أن Git من سطر الأوامر يملك بيانات الدخول المطلوبة. إذا فشل Push يُحفظ رقم الـCommit محلياً ولا يُدّعى النجاح؛ بعد حل مشكلة الاتصال أو المصادقة، أرفق نفس ZIP مجدداً ووافق على معاينة إعادة الدفع، دون إنشاء Commit مكرر.

## ضوابط مهمة

- المستودع المستهدف في هذا الإصدار **محدد**: `maenish-ai/YourAssistantAgent` فقط؛ يتم التحقق من Remote `origin` قبل أي تغيير.
- المستودع المحلي يجب أن يكون نظيفاً من التعديلات غير المحفوظة؛ منعاً لرفع ملفات لم توافق عليها.
- ZIP يُفحص محلياً، وتُنسخ **ملفاته الداخلية** إلى المشروع؛ لا يُرفع ZIP كملف واحد، ولا تُحذف الملفات غير الموجودة داخله.
- يُمنع ZIP ذو مسارات تجتاز حدود المشروع، أو روابط رمزية، أو أسماء غير آمنة، أو ملفات أسرار ظاهرة، مع حدّ للحجم وعدد الملفات.
- النموذج السحابي Groq لا يتلقى محتويات ZIP أو مفاتيح GitHub ضمن هذا المسار.
- المعاينة تعرض الملفات التي ستُضاف وتُعدّل فقط، **ولا تعرض فرق السطور**. راجع التفاصيل المهمة بنفسك قبل الموافقة.
- قد يرفض GitHub الدفع بسبب حماية الفرع أو عدم إعداد بيانات Git أو الشبكة. عند فشل Commit أو Push، افحص حالة المستودع المحلي في GitHub Desktop.
- لا يوجد تجاوز للـ2FA أو CAPTCHA ولا تُجمع رموز GitHub داخل التطبيق.

## الاختبار

```powershell
$env:PYTHONPATH = "$PWD\src"
python -m pytest -q tests/test_github_upload_v430.py
```

**هذه حزمة ملفات مصدر وليست مثبت Windows.** راجع حالة التعديلات وطلبات الدمج على GitHub قبل تنزيل نسخة البناء المطلوبة. إعداد GitHub Actions الحالي قد يُظهر اسم Artifact قديم (v3.0.1) لكن اسم ملف Setup الجديد سيكون v4.3.0. لا يتم إنشاء GitHub Release تلقائياً.
