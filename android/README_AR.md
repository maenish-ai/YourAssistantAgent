# تطبيق Your Assistant لأندرويد 1.1

تطبيق أندرويد مستقل للتواصل مع مساعدك على كمبيوتر البيت. لا يستخدم Telegram، ولا يرسل كلمة مرور GitHub أو Facebook إلى الهاتف. يتطلب أندرويد 8.0 فأحدث.

## إضافات 1.1

سطح مكتب بصور متجددة، نقر وسحب وكتابة واختصارات، وتصفح/نقل ملفات حتى 256 MiB.
زر «أمر كمبيوتر» يجهز مهمة ذكية للموافقة. يتطلب تحديث Windows إلى 4.5 وتفعيل التحكم ومساعد الكمبيوتر من إعداداته.
تفاصيل الإعداد والقيود في `README_V450_AR.md` بجذر المشروع. الشاشة الرئيسية فقط، داخل جلسة Windows المفتوحة، دون تجاوز شاشات القفل أو UAC.

## الربط لأول مرة

1. ثبّت نسخة الكمبيوتر الجديدة، ثم افتح إعدادات **Android وGitHub** وفعّل الخدمة. اختر مجلد مستودع Git المحلي واحفظه.
2. انسخ رمز الاقتران من إعدادات الكمبيوتر. يظل الرمز محفوظاً مشفراً داخل التطبيق باستخدام Android Keystore.
3. جهّز عنوان **HTTPS** يصل إلى خدمة الكمبيوتر. الخدمة نفسها تستمع على `127.0.0.1` فقط، ولذلك تحتاج نفق HTTPS أو reverse proxy إلى منفذها. مثال مناسب هو Tailscale Serve على شبكة Tailscale الخاصة بك. تثبيت التطبيق وحده لا ينشئ النفق.
4. افتح تطبيق أندرويد، وأدخل عنوان HTTPS بدون مسار أو معاملات، وأدخل رمز الاقتران، ثم اضغط **حفظ واتصال**.
5. يظل برنامج الكمبيوتر مفتوحاً ومفتوح القفل ومتصلًا بالإنترنت حتى يستقبل الطلبات. يمكن إبقاؤه في شريط النظام حسب إعداداته.

## الاستخدام

- أرسل رسالة مثل «اعرض الجروبات اللي فيها كلمة الفحص».
- اختر **محادثة جديدة** لبدء جلسة مستقلة، مع إلغاء معاينات الجلسة السابقة.
- اختر **إرفاق ZIP** لإرسال ملف حتى 20 MiB إلى الكمبيوتر. استلام الملف لا يرفع تعديلاته إلى GitHub تلقائياً؛ انتظر المعاينة ثم اضغط زر الموافقة.
- راجع المنشورات والجروبات أو تغييرات GitHub في المحادثة، ثم اضغط **موافق — نفّذ** أو **إلغاء**. كل موافقة مرتبطة بالمعاينة المعروضة ولها صلاحية محدودة.
- بعد إرسال الأمر، انتظر النتيجة. عند انقطاع الشبكة أثناء الإرسال، راجع المحادثة قبل تكرار الطلب؛ قد يكون الكمبيوتر استلمه بالفعل.
- يستقبل التطبيق النتائج كل ثانيتين أثناء فتحه. لا يشغّل خدمة إشعارات في الخلفية؛ مهام الكمبيوتر تستمر، ويمكن مراجعة نتائجها عند العودة للتطبيق.

إضافة المتصفح وتسجيل الدخول إلى Facebook وصلاحيات GitHub تبقى مهيّأة على الكمبيوتر. التطبيق لا يتجاوز تسجيل الدخول أو التحقق بخطوتين.

## بناء APK

النسخ المثبّتة: Android Gradle Plugin **8.7.3**، وGradle **8.9**، وAndroid SDK **35**. استخدم JDK 17 أو 21. لا توجد مكتبات واجهة أو خدمات تتبع خارجية.

من Android Studio: افتح مجلد `android`، وثبّت SDK 35، ثم ابنِ تطبيق Debug.

من الطرفية بعد تثبيت JDK وSDK:

```sh
cd android
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

على Windows استخدم `gradlew.bat` بدلاً من `./gradlew`. يحمل Wrapper نسخة Gradle 8.9 ويتحقق من بصمتها المثبتة قبل تشغيلها.

سيكون الملف في:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

نسخة Debug موقّعة بمفتاح التطوير ومناسبة للتجربة اليدوية. نشر نسخة متجر أو تحديثات مستقرة يحتاج مفتاح توقيع Release خاص بك.
