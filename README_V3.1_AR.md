# Your Assistant Agent v3.1 — المرحلة الأولى (نسخة تطويرية)

هذه حزمة **نواة تجريبية مستقلة**، وليست إصدارًا جاهزًا لاستبدال البرنامج الحالي.

## الموجود فعلًا
- فحص ZIP وفكّه في مساحة عمل مؤقتة ضمن المسارات المسموحة، مع منع المسارات الخارجة والروابط الرمزية وحدود الحجم.
- مقارنة الملفات المقترحة دون تعديل ملفات المشروع.
- فحص Git المحلي قراءة فقط.
- مخزن PIN محلي باستخدام scrypt مع قفل مؤقت بعد محاولات فاشلة.
- موافقات محددة بنوع العملية وبصمتها وتُستخدم مرة واحدة.
- ذاكرة تفضيلات محلية لا تحفظ إلا التفضيلات المؤكدة من المستخدم.
- اختبارات وحدات تلقائية.

## غير مكتمل بعد
- ربط المحرك بواجهة المحادثة وGroq tool calling.
- أزرار الموافقة وPIN في Tkinter.
- تنفيذ الدمج والـ Commit والـ Push؛ غير موجود عمدًا حتى تكتمل حماية المعاملات.
- طابور المهام والاستعادة وسجل 30 يومًا والتحكم الرسومي.
- اختبارات Windows الفعلية والبناء إلى EXE.

## اختبار الوحدة
من جذر المشروع بعد نسخ المجلد `src/yaa_lite`:

`set PYTHONPATH=src`

`python -m unittest discover -s tests -p test_smart_actions_v310.py -v`

لا تضف استدعاءً تلقائيًا للوحدة في launcher.py بعد؛ هي مكتبة مستقلة لا تنفذ شيئًا وقت الاستيراد. احتفظ بنسخة من مشروعك قبل الدمج.
