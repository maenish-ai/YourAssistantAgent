# Android 1.7.0 — Your Assistant

ماسح الاقتران يفتح الآن عمودياً بدلاً من شاشة ZXing الافتراضية الأفقية، ويستخدم دورة حياة الكاميرا نفسها وطلب الإذن ورفض الرموز غير المتعلقة بالتطبيق. يبقى اتجاه سطح المكتب متاحاً بحسب طريقة إمساك الهاتف. اختبارات الكاميرا تعمل على Android 9 وAndroid 15؛ يلزم أيضاً تجربة الكاميرا الفعلية على جهازك.

يتوفر **إعدادات الربط ← تشخيص الاتصال** منذ 1.6.1 لمعرفة إصدار الكمبيوتر وآخر رمز خطأ دون استخدام Groq. هذا التقرير لا يختبر تسجيل دخول فيسبوك مباشرة.

حدّث الكمبيوتر إلى Windows 5.0 لاستخدام الإملاء واختيار النوافذ. اقرأ `../README_V500_AR.md`.
زر إملاء صوتي يسجّل حتى دقيقة وأنت داخل التطبيق، ثم يرسل التسجيل للكمبيوتر ومنها إلى Groq. يعود النص إلى خانة الكتابة لتعدّله وترسله بيدك. لا ينفّذ الكلام تلقائياً، ولا يحمل الهاتف مفتاح Groq. رفض الميكروفون لا يمنع الكتابة. أضيفت أزرار لاختيار نافذة وإغلاق تبويب أو نافذة من شاشة سطح المكتب.

إصلاح 1.5.1: إضافة مكتبات AndroidX التي يحتاجها ماسح ZXing عند التشغيل. أعاد الاختبار الخروج الفوري عند الضغط على مسح QR بسبب غياب FragmentActivity في 1.5.0. الاختبارات الجديدة تفتح شاشة الكاميرا فعلياً وتغطي طلب الإذن، منحه، رفضه، إلغاء المسح ورفض رمز غير متعلق بالتطبيق. اقرأ `../README_ANDROID_V151_AR.md` للتحديث؛ لا يلزم تحديث Windows 4.9 لهذا الإصلاح.

الاقتران الأساسي HTTPS مباشر مع خادم مدمج في برنامج Windows 5.0.
لا تحتاج Render أو Tailscale أو برنامجاً إضافياً. افتح ربط الهاتف على الكمبيوتر، اختر الصلاحيات، واضغط تشغيل وعرض QR، ثم امسحه من الهاتف على Wi-Fi البيت.

للوصول من الخارج يلزم Public IPv4 مع توجيه منفذ أو IPv6 عام قابل للوصول. CGNAT بلا IPv6 يمنع الوصول المباشر ضمن شرط عدم وجود وسيط. المحادثة الذكية ما زالت تستخدم Groq؛ الشاشة والملفات اليدوية مباشرة بين الجهازين.

اقرأ `../README_V490_AR.md` للتحديث وإصلاحات Facebook والعربية، و`../README_V480_AR.md` للشبكة، و`../README_V470_AR.md` لتوقيع Release.

تحدد الحقول والنصوص اتجاهها من أول حرف قوي، مع بقاء حقول العناوين والمفاتيح باتجاه مناسب لها. اختبر قارئ ZXing صورة QR مولّدة بنفس دالة برنامج الكمبيوتر وفك بيانات الاتصال منها. إملاء Android الجديد يرجع نصاً بعد إنهاء التسجيل؛ لا يضيف كتابة كلمة بكلمة أثناء الكلام.

للبناء: Java 17 وAndroid SDK 35 وGradle 8.9. شغّل من جذر المصدر:

```sh
gradle -p android testDebugUnitTest assembleDebug lintDebug
```

تحتاج نسخة Release موقعة متغيرات `YAA_ANDROID_KEYSTORE` و`YAA_ANDROID_STORE_PASSWORD` و`YAA_ANDROID_KEY_ALIAS` و`YAA_ANDROID_KEY_PASSWORD`؛ يجهزها workflow من Repository secrets. لا ترفع المفتاح أو كلمة مروره ضمن المصدر.
