Your Assistant Agent – v2.5 Fast Live Voice

1) احتفظ بنسخة احتياطية من مجلد المشروع أولاً. لا تحذف .env ولا ترفعه إلى GitHub.
2) فك هذا ZIP وانسخ الملفات الموجودة بداخله إلى جذر مستودع YourAssistantAgent الذي يحتوي launcher.py وsrc و.github، مع Replace/Merge.
3) هذه الحزمة تراكمية: تتضمن ملفات v2.4 المطلوبة فوق قاعدة v2.3 GroqCloud التي ثبتتها سابقًا. لا تحتاج تنزيل v2.4 منفصلًا.
4) في CMD داخل مجلد المستودع نفّذ:
   set PYTHONPATH=%CD%\src && python -m pytest -q
5) بعد نجاح الاختبارات تأكد في GitHub Desktop أن .env ليس ضمن Changes، ثم Commit ثم Push origin.
6) انتظر اكتمال GitHub Actions بنجاح، ونزّل Installer جديدًا، وثبته. من edge://extensions أعد تحميل (Reload) إضافة Your Assistant Agent.
7) جرّب «افتح فيسبوك»، «افحص حالة الفيسبوك»، «حدث المجموعات»، ثم زر «إملاء إلى النص» وزر «محادثة صوتية».

الأوامر الصوتية/فيسبوك الحساسة مثل النشر والجدولة ما زالت تحتاج موافقة المستخدم؛ لا حاجة لبطاقة ائتمان.
النسخة القديمة المثبتة لا تتغير لمجرد نسخ ملفات المصدر؛ يلزم Push وبناء Installer جديد ثم تثبيته.
