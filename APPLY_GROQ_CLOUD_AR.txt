YOUR ASSISTANT AGENT — GROQCLOUD PATCH
======================================

هذه حزمة انتقال من العقل المحلي Qwen إلى GroqCloud.

التغييرات الرئيسية:
- العقل الرئيسي: openai/gpt-oss-120b على GroqCloud.
- أدوات Facebook والجدولة والموافقات تبقى محلية على جهازك.
- Tool Calling يبقى عبر مخطط أدوات البرنامج نفسه.
- الصوت: الميكروفون محلي، وتحويل الكلام إلى نص عبر Groq whisper-large-v3-turbo.
- الرد الصوتي يبقى Piper الأردني محليًا.
- بناء Windows على GitHub لا يحمل Qwen GGUF أو llama.cpp أو whisper.cpp المحلي.
- الحزمة لا تحتوي على أي API key.

طريقة التركيب المحلية:
1) أغلق البرنامج.
2) افتح ملف ZIP.
3) حدّد كل الملفات والمجلدات الموجودة داخله.
4) انسخها إلى جذر مجلد YourAssistantAgent نفسه.
5) وافق على Merge/Replace عندما يطلب Windows.
6) لا تحذف .env الموجود عندك، ولا ترفعه إلى GitHub.
7) بعد النسخ شغّل الاختبارات قبل أي Push إلى GitHub.

ملاحظة:
- بعض الأسماء الداخلية القديمة مثل QWEN/HAMMER تبقى للتوافق مع قاعدة البيانات والاختبارات القديمة.
- العقل الفعلي في runtime بعد هذا التعديل هو GroqCloud GPT-OSS 120B.
- نختبر محليًا أولًا، وبعد نجاح الاختبارات فقط نرفع التعديل إلى GitHub.
