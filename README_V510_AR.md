# تحديث Windows 5.1.0 وAndroid 1.7.0

هذا الإصدار يصلح اختلاف مسارات التنفيذ بين محادثة الهاتف والتحكم بالمتصفح، واختلاف جلسة فيسبوك المفتوحة عن جلسة البحث والنشر. لا يغيّر أسماء الصفحات أو يعتبر الأمثلة تعليمات فعلية.

## ما تم إصلاحه

- **فتح المواقع:** فتح GitHub وWhatsApp Web والمتصفح وأوامر الروابط البسيطة يستدعي أداة الفتح مباشرة، دون انتظار قراءة عناصر الشاشة أو قرار نموذج اللغة. الاسم غير المحدد يُبحث عنه؛ لا يُخترع له رابط.
- **فيسبوك:** أوامر فتحه البسيطة من الهاتف تصل إلى متصفح التحكم نفسه الذي تستخدمه قراءة المنشورات واكتشاف المجموعات ومعاينة النشر. فحص الخلفية لا يستبدل حالة الجلسة المُدارة بحالة إضافة متصفح آخر. القراءة الناجحة تزيل حالة الخطأ القديمة، ويظهر طلب تسجيل الدخول أو التحقق كحالة مستقلة.
- **الصفحات بطيئة التحميل:** انتهاء مهلة انتظار المتصفح لا يُعتبر فشلاً في الفتح إذا كان الهدف المطلوب نفسه ظاهراً ومحملاً. الصفحة الفارغة أو رابط مختلف لا يُعتبران نجاحاً.
- **طلبات متعددة الخطوات:** مسار فيسبوك يسمح حتى 12 خطوة تخطيط ضمن مهلة ثلاث دقائق، بدلاً من التوقف بعد خمس خطوات. مسار الكمبيوتر يحتفظ بسياق آخر أربع مهام معتمدة خلال المحادثة؛ يعيد قراءة الشاشة قبل استخدام معرّف نافذة أو تبويب. محادثة جديدة تمسح هذا السياق.
- **الإغلاق:** إذا كانت نافذة المساعد في المقدمة، يُستخدم المتصفح الوحيد الظاهر لإغلاق تبويبه. عند وجود عدة متصفحات يلزم اختيار النافذة، حتى لا تُغلق نافذة مختلفة. فشل آخر خطوة تنفيذية لا يتحول إلى رسالة نجاح من النموذج.
- **ماسح QR:** شاشة مسح مستقلة بوضع عمودي، بدلاً من الوضع الأفقي الافتراضي لمكتبة المسح. هوية الاقتران والصلاحيات السابقة محفوظة.
- **ZIP والمستودع:** اكتشاف نسخة محلية موجودة للمستودع المضبوط داخل المجلدات المعتادة، بمطابقة عناوين fetch وpush. تُحفظ النسخة المطابقة للاستخدام لاحقاً. تعدد النسخ يحتاج تحديد المجلد مرة واحدة؛ لا يتم اختيار مستودع مختلف بصمت.
- **فك الضغط:** المعاينة تعرض مجلداً تحت سطح المكتب `YourAssistantAgent-Uploads/<repo>-<hash>`. بعد الموافقة تُحفظ ملفات ZIP الكاملة هناك ثم تُطبق التغييرات في نسخة المستودع المحلية ويُنفذ Commit وPush عبر Git. يظهر الـCommit نفسه في GitHub Desktop. يدعم سطح المكتب المحوّل إلى OneDrive عبر مجلدات Windows المعروفة. لا تتم الكتابة فوق مجلد فك ضغط سبق تعديله.
- **مصدر البرنامج:** ملف شهادة الاختبار العام الموجود في مصدر Android مسموح فقط بمساره وبصمته المعروفين؛ كان يمنع رفع مصدر البرنامج نفسه سابقاً. مفاتيح التوقيع الخاصة تبقى مرفوضة.

## تثبيت التحديث

1. فك `YourAssistantAgent-v5.1.0-source.zip` وانسخ **محتوياته** إلى جذر مستودعك المحلي، بما فيها `.github`؛ لا تضع ملف ZIP وحده في المستودع.
2. اعمل Commit وPush من GitHub Desktop، ثم افتح GitHub Actions وشغّل **Build Windows Setup**. نزّل artifact باسم **YourAssistantAgent-Windows-Setup-v5.1.0** وثبّت EXE منه. لا يوجد مثبّت Windows مبني في الحزمة المحلية؛ بناؤه يتم على Windows في Actions.
3. ثبّت **Android 1.7.0 release** فوق نسخة Release السابقة. إذا كانت النسخة المثبتة Debug، استخدم **debug-upgrade** من الحزمة. التوقيع مطابق لملفات التحديث السابقة ولا تحتاج حذف التطبيق.
4. أغلق نسخة الكمبيوتر القديمة ثم افتح الجديدة. من الهاتف استخدم **إعدادات الربط ← تشخيص الاتصال** وتأكد أن إصدار Windows هو **5.1.0**. تحديث الهاتف وحده لا يصلح أدوات الكمبيوتر القديمة.

## تجربة متسلسلة

- من الهاتف اطلب «افتح فيسبوك». النافذة المفتوحة هي جلسة التحكم التي ستستخدمها الأدوات اللاحقة. إن طلب الموقع الدخول، أكمله من **سطح المكتب** على الهاتف؛ لا يلزم الرجوع جسدياً إلى الكمبيوتر.
- اطلب البحث عن اسم صفحتك الحقيقي أو أعط رابطها، ثم قراءة آخر منشور. إذا تعددت النتائج، اختر رابط الصفحة المقصودة.
- اطلب تجهيز المنشور للمجموعات المطابقة للكلمة المطلوبة. راجع المنشور وكل المجموعات الفعلية في المعاينة، ثم وافق. الموقع أو المجموعة قد يفرضان مراجعة أو يمنعان المشاركة؛ لا يضمن البرنامج تجاوز ذلك، ولا ينشئ حملة Ads Manager مدفوعة.
- جرّب فتح GitHub ثم إغلاق التبويب. عند تعدد النوافذ، استخدم **سطح المكتب ← اختيار نافذة** لتحديد المتصفح المطلوب.
- أرفق ZIP لمستودعك. راجع اسم المستودع والفرع والمجلد والملفات قبل الموافقة. إذا لم توجد نسخة محلية، أنشئ Clone مرة واحدة في GitHub Desktop أو حدد مجلدها في الإعدادات. تسجيل الدخول إلى Desktop وحده قد لا يوفّر مصادقة Git لسطر الأوامر؛ عند فشل Push يبقى الـCommit المحلي ويمكن دفعه من Desktop أو إعادة المحاولة بعد ضبط المصادقة.

## الاستخدام من شبكة ثانية

الاتصال بالشاشة والملفات مستضاف على الكمبيوتر عبر HTTPS. المحادثة والتخطيط والتفريغ الصوتي يستخدمان Groq كما اختار صاحب البرنامج. البرنامج لا يحتاج خدمة استضافة مدفوعة للوضع المباشر.

يلزم ضبط عنوان HTTPS خارجي يمكن للهاتف الوصول إليه، وتوجيه المنفذ إلى الكمبيوتر أو IPv6 عام قابل للوصول، مع إعداد جدار الحماية المناسب. QR يضم العنوان المحلي والخارجي المضبوطين؛ لا يجعل عنوان البيت المحلي قابلاً للوصول من الإنترنت ولا يتجاوز CGNAT. إذا منع مزود الإنترنت الوصول المباشر، فلا يمكن ضمان الاتصال الخارجي بلا تغيير إعداد الشبكة أو توفير مسار وسيط؛ البرنامج لا يستطيع إصلاح ذلك بمجرد تعديل واجهته.

تقرير **تشخيص الاتصال** يميز العنوان المحلي عن الخارجي ويوضح إذا لم يُضبط مسار خارجي. وجود عنوان في الإعدادات لا يعني نجاح تجربة خارجية. بعد التجهيز، أوقف Wi-Fi الهاتف وجرّب عبر بيانات الهاتف قبل مغادرة البيت. اترك الكمبيوتر مستيقظاً وجلسة المستخدم والبرنامج مفتوحين. شاشة قفل Windows وUAC خارج التحكم المعتاد.

## التحقق والحدود

الحزمة تتضمن تقرير الاختبارات والبصمات. الاختبارات الآلية تغطي توجيه أوامر الهاتف عبر التطبيق الفعلي، مشاركة جلسة فيسبوك بين الأدوات، حالات المتصفح، ملفات ZIP وعمليات Git محلية، ودورة حياة كاميرا Android على نسختين من النظام. لا تتضمن دخول حساب صاحب البرنامج أو نشراً فعلياً أو تجربة Windows/هاتف/راوتر حقيقية في هذه البيئة.

التحكم اليدوي بالصورة والماوس والكيبورد متاح للبرامج داخل جلسة Windows المسموح بها؛ الأتمتة الذكية تعتمد على أدواتها وعناصر الواجهة المتاحة. لا يمكن ضمان تنفيذ كل إجراء في كل برنامج أو تجاوز صلاحيات النظام. إذا فشلت خطوة، أرسل تقرير التشخيص ونص الأمر الفعلي؛ لا ترسل كلمات المرور أو رمز QR.
