Your Assistant Agent v3.0.1 — إصلاح عرض العربية

السبب: كانت v3.0 تعيد تشكيل وقلب اتجاه الكلمات العربية باستخدام arabic_reshaper و python-bidi قبل التفاف سطور Tkinter. أدى هذا لتقطيع الكلمات في الرسائل الطويلة.

ما تغير:
- عرض النص العربي الأصلي Unicode بلا قلب أو إعادة تشكيل مسبقة.
- الحفاظ على النص كما هو للعرض والنسخ والتخزين، والاعتماد على محاذاة الرسائل إلى اليمين.
- إزالة مكتبات تشكيل عربية لم نعد نستخدمها من requirements.
- تحديث إعدادات نسخة Windows إلى v3.0.1 واختبارات الانحدار.

التركيب: فك ZIP وانسخ المجلدات والملفات فوق نسخة مشروع GitHub الكاملة (النسخة v3.0). ارفعها بعد مراجعة التغييرات ثم انتظر GitHub Actions يبني Setup. احتفظ بملف .env خارج GitHub.

تنبيه: هذا إصلاح محدد لمشكلة تقطيع الكلام، ولم يتم اختباره بعد على جهاز Windows الفعلي. قد يحتاج نص عربي-إنجليزي معقد إلى تحديث عنصر العرض في مرحلة لاحقة. لا يُغير الصوت أو الموافقات أو صلاحيات GitHub.
