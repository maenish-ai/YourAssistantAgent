# Your Assistant 4.7 — Windows وAndroid معاً

نسخة Windows في المصدر: **4.7.0**. نسخة Android: **1.3.0**.
واجهة مشتركة بالبنفسجي والأزرق وأيقونة المساعد الأصلية نفسها. تطبيق Android مستقل، ولا يحتاج Telegram.

## ما الذي أصبح متاحاً؟

- ربط الهاتف من زر **ربط الهاتف QR / Pair phone QR** في الشريط العلوي للكمبيوتر.
- الرمز يظهر داخل صفحة الربط بعد تجهيز الخادم، وعند حفظ الإعدادات الصحيحة؛ لا تحتاج البحث في نافذة أخرى.
- صفحة الربط تعرض ثلاث خطوات وحالة اتصال تتحدث تلقائياً. إذا لم يُجهّز الخادم، توضح ذلك صراحةً ولا تعرض رمزاً وهمياً.
- Android يحفظ الاقتران مشفّراً، ويحاول إعادة الاتصال أثناء فتح التطبيق. أزرار الشاشة والملفات والمساعد تتاح بحسب صلاحيات الكمبيوتر.
- عرض الشاشة الرئيسية والنقر والزر الأيمن والنقر المزدوج والسحب والتكبير والكتابة بالعربية واختصارات لوحة المفاتيح. لوحة الأدوات تُفتح عند الحاجة لتبقى مساحة الشاشة أكبر.
- نقل ملفات حتى **256 MiB** في الاتجاهين مع تقدّم النقل وإمكانية الرجوع لإلغائه. نقل الخادم الوسيط يجري على دفعات مع فحص SHA256.
- خيار **إتاحة كل الأقراص المحلية للهاتف** يضيف قائمة أقراص Windows المحلية والثابتة/القابلة للإزالة؛ أو يمكنك إبقاء الوصول إلى مجلد محدد. الملفات الموجودة لا تُستبدل.
- خيار **منع السكون التلقائي أثناء الربط وعلى الشاحن** يمنع السكون الناتج عن الخمول فقط أثناء تشغيل خدمة الهاتف وتوصيل الطاقة. إيقاف الربط يعيد سلوك الطاقة الطبيعي. لا يوقظ جهازاً نائماً ولا يتجاوز السكون الذي تطلبه يدوياً أو إغلاق الغطاء.
- أوامر الكمبيوتر الذكية تستعمل عناصر واجهة Windows المرئية وتطلب موافقة على المهمة. أتمتة Facebook ورفع ZIP إلى GitHub تحافظ على المعاينة والموافقة قبل النشر.

## قبل الاستخدام من خارج البيت

**لا يوجد خادم عام منشور أو عنوان خدمة جاهز داخل هذه الحزمة.** المصدر وAPK لا ينشئان حساب استضافة. بعد نشر الخادم مرة واحدة، مسح QR يكفي للاستخدام اليومي دون كتابة عنوان أو مفتاح على الهاتف.

يلزم كمبيوتر Windows مستيقظ، جلسة المستخدم مفتوحة، وبرنامج المساعد شغّال ومفتوح القفل. يمكن تشغيله مع Windows من إعدادات بدء التشغيل. إذا اخترت كلمة مرور للبرنامج، يبقى فتح قفله مطلوباً بعد إعادة التشغيل.
التحكم لا يتجاوز قفل Windows أو شاشة UAC ولا صلاحيات حساب المستخدم، ولا يوفر بثاً صوتياً أو فيديو سريعاً أو اختيار شاشات متعددة. بعض البرامج لا تكشف عناصر قابلة للأتمتة؛ استخدم التحكم اليدوي حينها. مصطلح «كل الأقراص» لا يتجاوز أذونات Windows.

## ١ — ارفع المصدر وابنِ نسخة الكمبيوتر

1. أغلق البرنامج القديم، وفك ملف **source.zip** في مجلد مؤقت.
2. انسخ **محتويات** مجلد المصدر إلى جذر نسخة مستودعك المحلية التي يفتحها GitHub Desktop؛ لا تضعها داخل مجلد إضافي. لا تحذف مجلد `.git` أو بيانات برنامجك.
3. أزل من جذر المستودع أي APK قديم مثل `YourAssistantAgent-Android-v1.0.0-debug.apk` وملف checksum القديم `YourAssistantAgent-v4.4-SHA256.txt` إن كانا موجودين؛ المصدر الجديد لا يوزع هذه الملفات القديمة.
4. اعمل Commit وPush. احتفظ بملف workflow واحد: `.github/workflows/build-windows.yml`. أزل `windows-build.yml` القديم إن كان موجوداً حتى لا تبقى إشارة حمراء من مسار بناء قديم.
5. من تبويب **Actions** افتح **Build Windows Setup**، وانتظر نتيجة **هذا الـcommit**. يمكن أيضاً تشغيله عبر Run workflow. نجاح بناء Android لا يعني أن بناء Windows اكتمل.
6. نزّل Artifact **YourAssistantAgent-Windows-Setup-v4.7.0**، وفك ملفه وثبّت EXE. برنامج التثبيت يحافظ على بيانات التطبيق الموجودة خارج مجلد البرنامج.
7. تأكد من وجود زر **Pair phone QR / ربط الهاتف QR** أعلى البرنامج؛ شغّل البرنامج المثبّت حديثاً بدلاً من EXE قديم في مجلد آخر.

الحزمة تضم مصدر Windows وليس مثبّت Windows مبنياً سلفاً. للتشغيل من المصدر: Python 3.11، ثم `python -m pip install -r requirements.txt` وبعدها `python launcher.py`.

## ٢ — جهّز خادم الربط مرة واحدة

### عبر Render

المصدر يحتوي `render.yaml` لإنشاء خادم Python واحد مع HTTPS وفحص صحة ومفتاح تسجيل يُولّد لدى الاستضافة.
بعد رفع المصدر، افتح https://render.com/deploy?repo=https://github.com/maenish-ai/YourAssistantAgent واربط مستودعك.
القالب يختار خطة **starter** مدفوعة للبقاء متصلاً؛ راجع سعرها وحدود حركة البيانات في Render قبل الموافقة. لم تُنشأ خدمة مدفوعة بواسطة تجهيز هذه الملفات.
إذا أردتني أن أنشره، يلزم ربط حساب Render هنا أولاً. عدم ربط الحساب لا يمنع تجهيز بقية الكود.

بعد نجاح النشر:

1. خذ رابط `https://…onrender.com` من الخدمة. افتح `/health` وتأكد أنه يعرض `ok: true`.
2. خذ `RELAY_ENROLLMENT_KEY` من Environment في حساب الاستضافة واحفظه بشكل خاص.
3. أنشئ ملف إعداد الكمبيوتر محلياً من المصدر:

```sh
python scripts/create_desktop_setup.py --url https://YOUR-SERVICE.onrender.com
```

يطلب المفتاح دون إظهاره. ينتج `desktop-setup.json`؛ لا ترفعه إلى GitHub. يمكن بدلاً من ذلك إدخال العنوان والمفتاح في «الإعداد المتقدم» على الكمبيوتر مرة واحدة.

### عبر VPS تملكه

ملفات Docker وCaddy موجودة في `relay_server/`. راجع `README_V460_AR.md`، وجهّز النطاق ثم شغّل:

```sh
cd relay_server
python3 setup.py --domain relay.YOUR-DOMAIN.com
docker compose up -d --build
```

لا تحتاج فتح منافذ في راوتر البيت. الخادم العام هو الذي يستقبل الاتصال؛ الكمبيوتر والهاتف يتصلان به للخارج. أبقِ نسخة واحدة للخادم ومفتاح التسجيل ثابتاً بعد إعادة التشغيل.

## ٣ — امسح QR وابدأ

1. في Windows اضغط **ربط الهاتف QR** ثم **استيراد ملف إعداد الخادم**.
2. اختر صلاحيات الشاشة والملفات والمساعد، واختر كل الأقراص إذا أردت إتاحتها. اضغط **حفظ الصلاحيات وتفعيل الربط وعرض QR**.
3. انتظر حالة اتصال الخادم. افتح Android واضغط **مسح QR وإقران الكمبيوتر** واسمح بالكاميرا.
4. بعد الاتصال، افتح سطح المكتب أو الملفات أو أرسل طلباً للمساعد. كل جهاز مقترن يملك الصلاحيات التي حددتها؛ لا تنشر الرمز.
5. جرّب طلباً بسيطاً وأنت على شبكة البيت، ثم أوقف Wi-Fi على الهاتف وجرّب عبر بيانات الهاتف للتحقق من الوصول من الخارج.

**قطع الاتصال** يوقف إعادة الاتصال في الهاتف. تغيير المفتاح من الكمبيوتر يلغي الاقتران القديم؛ الرمز ليس رمزاً يستخدم مرة واحدة أو ينتهي تلقائياً. **إيقاف اتصال الهاتف** يمنع استقبال طلبات جديدة على الكمبيوتر، ولا يتراجع عن عمل نُشر بالفعل.

عند تعطل النقل قد يبقى تنزيل جزئي على الهاتف؛ احذفه وأعد التنزيل. عند انقطاع أمر، راجع الشاشة أو المحادثة قبل تكراره. لا تفترض أن كل طلب فاشل الاتصال لم يصل.

## توقيع Android والتحديثات

APK باسم **release** موقّع بمفتاح توزيع خاص وثابت. احتفظ بحزمة التوقيع الخاصة المرفقة بشكل منفصل؛ لا تضعها في المستودع العام.
للبناء بالمفتاح نفسه على GitHub، أضف القيم الأربع من ملف `github-secrets.json` إلى **Settings → Secrets and variables → Actions** كـ Repository secrets. بعدها ينتج workflow Artifact **YourAssistantAgent-Android-Release-v1.3.0** إلى جانب نسخة Debug للتجربة.
من دون هذه الأسرار يُبنى Debug فقط؛ لا يُختلق توقيع توزيع جديد عند كل بناء.

إذا كنت مثبتاً APK الـDebug القديم، Android سيرفض تحديثه بـRelease لأن التوقيع مختلف. احذف نسخة Debug مرة واحدة وثبّت Release ثم أعد الاقتران. تُفقد بيانات التطبيق المحلية عند الحذف؛ مهام الكمبيوتر وملفاته تبقى عليه. بعد أول Release، استخدم المفتاح نفسه لكل تحديث.

إذا أردت إنشاء مفتاحك بنفسك بدلاً من المفتاح المرفق، شغّل `python scripts/prepare_android_signing.py` باستخدام Java 17 واحتفظ بناتجه خارج Git. لا تستبدل مفتاح نسخة Release مثبتة بالفعل.

## الخصوصية وحدود التحقق

الخادم يمرر رسائل AES-256-GCM ولا يملك مفتاح فكها؛ مفاتيح التسجيل وأدوار الهاتف والكمبيوتر منفصلة. رمز الاقتران يبقى على الكمبيوتر وهاتفك. سجل الطلبات يمنع تكرار تنفيذ الرسائل نفسها.
المحادثة وأسماء عناصر النافذة التي يستخدمها مساعد الكمبيوتر تُرسل إلى Groq حسب الإعداد. صور الشاشة ومحتويات الملفات لا تُرسل إلى Groq بواسطة مساعد الكمبيوتر.
الاختبارات الآلية والبناء المحلي وفحص واجهة Tk لا يثبتون أن ربطك العام أو كاميرا هاتفك أو برامج Windows لديك تعمل فعلياً. يلزم اختبار الأجهزة وخادمك بعد النشر. لا توجد خدمة عامة منشورة سلفاً ضمن التسليم.
