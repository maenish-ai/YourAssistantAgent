# تحسين المحادثة وحالة النتائج

- صيغ مثل «شو رأيك...» و«برأيك...» تعامل كنقاش في الصيغ المدعومة، ولا تُنفّذ أدوات تلقائياً. لا يلغى طلب الموافقة المعلق بسبب سؤال رأي أو فشل الاتصال أثناءه.
- إذا لم يستدع وكيل الكمبيوتر أي أداة، لا تُعرض الإجابة على أنها دليل على تنفيذ المهمة. وكذلك لا تعتبر نقرة أو فتح صفحة دليلاً مستقلاً على النشر أو الإرسال أو الحذف أو الرفع؛ تعرض الحالة «لم يُتحقق من النتيجة» عندما ينقص الدليل.
- هذه ضوابط محددة، وليست فهماً مضموناً لكل صيغة أو آلية تحقق نهائية لكل المواقع. قد تحتاج لاختيار الوجهة أو فحص النتيجة بنفسك، خصوصاً قبل إعادة عملية إرسال أو نشر.
- لتظهر تسمية الحالة الجديدة في الهاتف، ابنِ وحدّث Android وWindows معاً. بناء Debug للتجربة فقط وقد لا يحدث التطبيق القديم إذا اختلف مفتاح التوقيع. لم تجرِ تجربة فعلية على هاتف أو Windows أو حساب متصل.

التحقق المحلي: نجح اختبار Python شامل بـ539 نتيجة ناجحة و8 متجاوزة، ثم نجحت 124 حالة مركزة بعد إضافة حالة فشل النقاش. نجح بناء Android و35 اختباراً آلياً، مع صفر أخطاء و21 تحذير Lint. لم يُختبر اتصال حقيقي أو نشر أو صوت أو تثبيت على جهاز فعلي.
