Your Assistant Agent v1.3.0 — FULL PROJECT FOR GITHUB

1) فك ZIP المشروع الكامل.
2) ارفع محتويات المجلد إلى مستودع GitHub.
3) Commit + Push.
4) افتح Actions وانتظر Build Your Assistant Agent for Windows.
5) حمّل Artifact باسم YourAssistantAgent-Windows-Setup.

بعد التثبيت:
- افتح Chat وتكلم مع الوكيل بشكل طبيعي.
- اربط Facebook مرة واحدة؛ إذا لم توجد جروبات سيحاول اكتشافها تلقائيًا.
- من Settings أدخل اسمك/نشاطك وصفحة Facebook الافتراضية.
- للنسخ المجاني: ثبّت Google Drive for desktop، اختر مجلدًا داخل Drive، فعّل Automatic encrypted backup، ثم اعرض Recovery Key وخزّنه بمكان آمن.

مهم: ملف الـAI الكبير لا يوجد في Source ZIP. GitHub Actions ينزله أثناء Build ويضعه داخل Setup النهائي.
