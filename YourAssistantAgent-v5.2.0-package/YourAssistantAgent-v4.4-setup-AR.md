# إعداد YourAssistantAgent 4.4 مع تطبيق Android

هذه النسخة تضيف تطبيق Android مستقلاً للتحكم بالمساعد الموجود على كمبيوتر البيت.
لا تحتاج بوت Telegram. تحتاج إعداد اتصال HTTPS مرة واحدة، وتشغيل برنامج الكمبيوتر.

## 1. تثبيت نسخة الكمبيوتر

1. فك ملفات المصدر الجديدة داخل المستودع المحلي، مع دمج المجلدات واستبدال الملفات المطابقة. لا تحذف الملفات الأخرى.
2. ارفع التعديلات بواسطة GitHub Desktop. بناء GitHub Actions ينشئ مثبت Windows وملف APK لتجربة Android.
3. ثبّت نسخة Windows الجديدة. رفع المصدر وحده لا يحدّث البرنامج المثبّت.
4. افتح البرنامج وأكمل القفل وإعداد مفتاح Groq كالمعتاد.

## 2. تجهيز GitHub

افتح **الإعدادات ← Android وGitHub**:

- اسم المستودع بصيغة `owner/name`، مثلاً `maenish-ai/YourAssistantAgent`.
- مجلد نسخة Git المحلية للمستودع. يمكنك تجهيزها أولاً باستخدام GitHub Desktop.

يتم حفظ الاختيار للمحادثات التالية. لا يتم إنشاء مستودع جديد أو استنساخه تلقائياً.
يجب أن يستطيع Git من سطر الأوامر عمل Commit وPush. تسجيل الدخول إلى GitHub Desktop وحده قد لا يكفي.
المجلد يجب أن يكون نظيفاً من تعديلات غير محفوظة قبل رفع ZIP.

## 3. ربط الهاتف من خارج البيت

1. من نفس صفحة الإعدادات، اضغط **إنشاء / تغيير مفتاح الاقتران**.
2. فعّل اتصال Android واحفظ. المنفذ الافتراضي `8766`.
3. ثبّت Tailscale على الكمبيوتر والهاتف واربطهما بنفس الحساب/الشبكة الخاصة.
4. على Windows، نفّذ:

   ```powershell
   tailscale serve --bg http://127.0.0.1:8766
   ```

5. اتبع تعليمات Tailscale لتفعيل HTTPS إذا ظهرت. احتفظ برابط HTTPS الذي يعرضه.
6. ثبّت تطبيق Android، وأدخل رابط HTTPS ومفتاح الاقتران الظاهر في برنامج الكمبيوتر، ثم اضغط **حفظ واتصال**.

العنوان `127.0.0.1` داخل الهاتف يشير للهاتف نفسه؛ استخدم رابط HTTPS الذي أعطاك إياه Tailscale.
لا تحتاج فتح منفذ في الراوتر. الخادم داخل البرنامج يستمع للكمبيوتر المحلي فقط، والاتصال الخاص يوصله للهاتف.
يجب بقاء Tailscale متصلاً على الجهازين، وبقاء كمبيوتر البيت مستيقظاً والبرنامج مفتوحاً أو في شريط النظام.
بعد إعادة تشغيل الكمبيوتر افتح البرنامج وافتح القفل أولاً. الإشعارات والنتائج تظهر عند فتح تطبيق الهاتف؛ لا توجد إشعارات خلفية في هذه النسخة.

تغيير مفتاح الاقتران يقطع صلاحية المفتاح القديم. إعادة تشغيل البرنامج تلغي أزرار الموافقة السابقة.

## 4. تجربة رفع ZIP

1. ابدأ محادثة جديدة في تطبيق Android.
2. اضغط **إرفاق ZIP** واختر الملف؛ الحد الأقصى 20 MiB.
3. ستظهر معاينة المستودع والفرع وجميع الملفات الجديدة والمعدلة. الملف لا يصل إلى Groq.
4. راجع المعاينة كاملة ثم اضغط **موافق — نفّذ**، أو **إلغاء**.
5. راقب النتيجة في المحادثة. كلمة «نعم» وحدها لا تبدأ الرفع، والزر يعمل مرة واحدة.

إذا فشل Push بعد إنشاء Commit، عالج المصادقة أو الشبكة على الكمبيوتر ثم أعد إرفاق نفس ZIP؛ تظهر معاينة لإعادة دفع الـCommit المعلّق دون تكراره.
إذا انقطع الاتصال أثناء إرسال أمر، افحص الرسائل والحالة قبل تكراره؛ قد يكون وصل للكمبيوتر.

## 5. تجهيز Facebook

1. حمّل مجلد `browser_extension` كإضافة غير مضغوطة في Chrome/Edge، وسجّل الدخول إلى Facebook.
2. أعد تحميل الإضافة إذا حدّثت ملفاتها.
3. النشر يستخدم متصفحاً مُداراً منفصلاً. اطلب **«افتح متصفح النشر لفيسبوك»** ثم أكمل تسجيل الدخول على الكمبيوتر مرة واحدة.
4. اطلب تحديث الجروبات واختيارها، مثلاً: **«اختار الجروبات التي تحتوي الفحص، واستثنِ الفحص التجارية»**.
5. أعطِ رابط الصفحة واطلب مشاركة منشور واحد أو حتى أربعة منشورات ظاهرة حديثة على الجروبات المختارة.
6. راجع **روابط المنشورات وأسماء وروابط الجروبات الفعلية** قبل الموافقة من الهاتف.

التنفيذ يلتزم بالروابط المعروضة حتى لو تغيّرت الصفحة أو قائمة الجروبات. طلب بدون موعد يعني مرة واحدة بعد الموافقة.
الجدول المتكرر يعيد نفس الروابط المعتمدة؛ المنشورات الجديدة تحتاج معاينة جديدة.
اختيار المنشورات يعتمد على روابط الصفحة الظاهرة، ولا يضمن ترتيباً زمنياً موثقاً ولا يدير إعلانات Meta المدفوعة.
تسجيل الدخول وCAPTCHA و2FA والتحقق الأمني خطوات يدوية. نتائج المجموعات قد تكون منشوراً مؤكداً أو إرسالاً أو انتظار موافقة؛ يعرض البرنامج الحالات منفصلة.

## 6. أوامر مساعدة

- `/new` محادثة جديدة.
- `/cancel` إلغاء المعاينة المعلّقة؛ لا يوقف عملية سبق أن بدأت.
- `/status` حالة البرنامج وتقدم مهمة Facebook.

هذه ملفات مصدر وتطبيق تجريبي. يجب تجربة الاتصال على جهازك وتجربة حساب Facebook قبل الاعتماد عليه في العمل الفعلي.
