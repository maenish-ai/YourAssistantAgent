ابدأ من هنا — أول رفع إلى GitHub

1) فك الضغط.
2) لا ترفع ملف ZIP نفسه كملف وحيد.
3) افتح المجلد الناتج في GitHub Desktop.
4) تأكد أن مجلد .github موجود في نفس مستوى app.py.
5) Commit.
6) Publish repository.
7) افتح GitHub > Actions.
8) Workflow سيعمل تلقائياً من أول Push.

Build Your Assistant Agent for Windows
