Your Assistant Agent v2.8 — إصلاح الصوت والمهام واستهلاك الخلفية

1) خذ نسخة احتياطية من مجلد المشروع الحالي.
2) فك ضغط ZIP ثم انسخ الملفات والمجلدات الموجودة بداخله فوق مجلد مشروع GitHub الأصلي مع المحافظة على المسارات. بما في ذلك مجلد .github المخفي.
3) لا تنسخ .env أو أي ملف يحتوي مفاتيح/كلمات مرور إلى GitHub؛ الحزمة لا تحتوي مفاتيح.
4) افتح GitHub Desktop، راجع ملفات التغيير، اعمل Commit ثم Push.
5) في GitHub > Actions > Build Windows Setup تأكد من نجاح البناء الأخضر، ثم نزّل النسخة الجديدة وثبتها.
6) داخل المحادثة اختر «فحص واختيار الميكروفون»، اختر الميكروفون الذي تستعمله في ChatGPT، اضغط «سجّل واسمع 4 ثوانٍ»، تأكد أنك سمعت التسجيل، ثم احفظ الاختيار.
7) جرّب «إملاء إلى النص» أولاً، وبعد نجاحه جرّب «محادثة صوتية» وNoura.
8) من صفحة المهام، جرّب زر Delete أو كليك يمين أو زر حذف على بطاقة مهمة غير مهمة، وراجع تأكيد الحذف.

تنبيه: الملفات تحديث على المصدر؛ مجرد نسخها على سطح المكتب لا يغير البرنامج المثبت إلى أن يتم بناء وتنزيل الـSetup الجديد.
الأمان: إذا كانت مهمة تنشر حاليًا، سيطلب البرنامج إيقافها أولاً قبل حذفها؛ وربما يتأخر توقف عملية المتصفح.
ملاحظات الاختبار: اجتازت اختبارات منطقية محلية لكن اختبار الميكروفون على جهازك وبناء Windows النهائي يلزمان للتحقق الكامل.
