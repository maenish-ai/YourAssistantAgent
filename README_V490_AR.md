# Your Assistant Agent — Windows 4.9.0 وAndroid 1.5.0

هذه حزمة مصدر محدثة وAPK أندرويد موقّع. مثبّت Windows EXE ينتج من GitHub Actions بعد رفع المصدر؛ لا تحتوي الحزمة على EXE مبني محلياً.

## التثبيت من GitHub

1. أغلق نسخة الكمبيوتر القديمة قبل التحديث. أغلق نافذة المتصفح التي فتحها المساعد سابقاً إذا بقيت مفتوحة، حتى لا تحجز ملف الجلسة القديم.
2. فك `YourAssistantAgent-v4.9.0-source.zip` على الكمبيوتر. انسخ **محتوياته** إلى جذر نسخة المستودع، بحيث يكون `launcher.py` و`pyproject.toml` ومجلد `.github` في الجذر. لا ترفع ZIP نفسه بدلاً من المصدر، ولا تضع المشروع داخل مجلد إضافي. استخدم GitHub Desktop لمراجعة الملفات وعمل commit وpush، مع تضمين حذف أي ملف قديم أزيل من المصدر.
3. من GitHub افتح Actions ثم **Build Windows Setup** وشغّل workflow، أو انتظر تشغيله بعد الرفع إلى `main`. عند نجاحه نزّل **YourAssistantAgent-Windows-Setup-v4.9.0**، فك ملف artifact وثبّت EXE بداخله. إذا فشل أي اختبار، لا تعتبر البناء جاهزاً؛ احتفظ برسالة الخطأ لمعالجتها.
4. ثبّت `YourAssistantAgent-Android-v1.5.0-release.apk` على الهاتف. أيقونته وهوية التطبيق متوافقتان مع نسخة الكمبيوتر. التوقيع نفسه المستخدم لنسختي Release 1.3 و1.4، لذا يحدثهما مباشرة. نسخة Debug القديمة لها توقيع مختلف؛ لا تحذفها قبل حفظ ما تحتاجه من إعداداتها، ثم استخدم نسخة Release هذه أو بناء Debug المناسب من Actions.
5. افتح النسختين الجديدتين، وتأكد من الأرقام 4.9.0 و1.5.0 قبل التجربة. تحديث أحد الجهازين وحده لا يصلح واجهة الجهاز الآخر.

لا ترفع مفتاح توقيع Android أو كلمات مروره أو ملف إعداد ربط شخصي إلى GitHub. بناء Release عبر Actions يحتاج أسرار التوقيع الموصوفة في دليل 4.7؛ APK المرفق موقّع بالفعل ولا يحتاج إعادة بنائه للتثبيت.

## Facebook: التنفيذ من المحادثة

أوامر مثل «فوت على الفيسبوك» و«فوت عالفيسبوك» تصل الآن إلى أداة فتح المتصفح فعلياً، حتى قبل طلب رد من النموذج. يستخدم المساعد متصفحاً مدعوماً مثبتاً، مثل Edge أو Chrome، وملف جلسة خاصاً به. لا ينسخ كلمات مرورك من ملف المتصفح الشخصي.

إذا طلب Facebook تسجيل الدخول أو التحقق، تكتب بياناتك بنفسك داخل النافذة التي فتحها المساعد، ثم **تتركها مفتوحة**. المساعد يعيد استخدام الجلسة نفسها للتحقق، واكتشاف الجروبات، وقراءة الصفحة وتجهيز النشر. لا يتجاوز التحقق بخطوتين أو CAPTCHA. إذا كنت داخل Facebook في نافذة شخصية أخرى، فقد تحتاج تسجيل الدخول مرة أولى في نافذة المساعد أيضاً.

أُزيل إصلاح قديم كان يستبدل دالة اكتشاف المجموعات عند بدء البرنامج. وأصبحت عمليات Playwright تنفّذ على خيط واحد يملك المتصفح، لأن تبديل الخيوط بين الهاتف والكمبيوتر كان يقطع التنفيذ. وتمنع الخدمة التنقل إلى صفحة أخرى أثناء عملية نشر قائمة.

أمثلة للتجربة، وليست أوامر تنفّذ بمجرد قراءة هذا الدليل:

- «فوت على الفيسبوك»: يفتح المتصفح أو تبويب الإضافة المتصلة.
- «تعرف على الجروبات»: يحاول اكتشاف مجموعات الحساب وحفظ النتائج الحقيقية.
- «ابحث عن صفحة اسمها …»: يعرض صفحات مرشحة بروابطها، لتختار الصفحة المقصودة إذا تشابهت الأسماء.
- «هات آخر منشور ظاهر من هذه الصفحة: [رابط الصفحة]»: يعيد روابط منشورات مرئية، دون نشرها.
- «هذا مثال فقط، لا تنفذ»: يوقف تنفيذ الطلب بوصفه مثالاً. يبقى المثال وصفاً ولا يتحول تلقائياً إلى استهداف كل المجموعات.

قراءة المنشورات تستخدم الروابط الفعلية وتستبعد روابط الألبومات والمنشورات التي تظهر عليها علامة التثبيت، وتحتفظ بمعرّفات المنشورات الموجودة في query. ترتيب الصفحة قد يتأثر بتخصيص Facebook؛ لا تدّعي الأداة تاريخاً لم تره أو تضمن ترتيباً زمنياً كاملاً. النشر يمر بمعاينة الروابط والمجموعات وموافقتك على الاختيار المحدد. تغير واجهة Facebook أو صلاحيات الحساب قد يحتاج تحديثاً لاحقاً؛ لم نجرّب حسابك الحقيقي من هذه البيئة.

## العربية والإملاء

نافذتا الكتابة والمحادثة على Windows تستخدمان محرر RichEdit المدمج في Windows لربط الحروف واتجاه الفقرة وحركة المؤشر. تُحفظ الكلمات بترتيب Unicode الأصلي، دون قلب النص قبل عرضه، ليبقى النسخ والإرسال صحيحين. وفي Android تتبع النصوص والحقول أول حرف قوي لتحديد الاتجاه، مع إبقاء عناوين الاتصال وحقول المفاتيح مناسبة للكتابة اللاتينية.

زر إنهاء الإملاء على Windows يحتفظ بآخر جزء مسجل وينتظر نتيجة التفريغ قبل تفعيل الإرسال. لا يرسل التسجيل تلقائياً. أُطيل هامش السكوت، وأُبقي معدل تسجيل الميكروفون الأصلي، وأضيف رفض التسجيلات القصيرة أو الصامتة لتقليل النص المختلق. يستخدم التفريغ Groq Whisper باللغة العربية دون إعادة صياغة كلامك. هذا يحسن مسار التسجيل ولا يضمن فهم كل لهجة؛ اختبر عبارة قصيرة واضحة واختر الميكروفون الصحيح. لا تضيف هذه النسخة زر إملاء جديداً على Android.

## QR والاتصال المباشر

من أعلى برنامج الكمبيوتر افتح **Pair phone QR** ثم **Start hosting and show QR**. المسار الافتراضي يستضيف HTTPS على الكمبيوتر نفسه؛ لا يحتاج Relay أو اشتراك استضافة. اختر صلاحيات الشاشة والإدخال والملفات التي تريدها، وافتح المساعد وهو غير مقفل. لا يولّد نجاحاً وهمياً: إذا فشل تشغيل الخادم، يجب حل الخطأ المعروض أولاً.

امسح الرمز من تطبيق Android على Wi-Fi البيت. يحوي بيانات الاتصال وبصمة الشهادة، ويحفظ الهاتف رمز الاقتران في Android Keystore. احتفظ بالرمز لنفسك؛ تدوير مفتاح الاقتران على Windows يلغي وصول الهواتف القديمة. نجح اختبار توليد صورة QR باستخدام دالة الإنتاج وفكها بمكتبة ZXing المستخدمة في Android؛ لم نختبر كاميرا هاتفك الفعلية هنا.

للعمل من خارج البيت، اقرأ [دليل الشبكة 4.8](README_V480_AR.md): يلزم عنوان IPv4 عام مع توجيه منفذ إلى الكمبيوتر، أو IPv6 عام قابل للوصول. **QR وحده لا يتجاوز CGNAT**. الاتصال المحلي لا يثبت نجاح الاتصال من بيانات الهاتف. لا تعدّل النسخة إعدادات الراوتر تلقائياً.

الشاشة والملفات والتحكم اليدوي تمر مباشرة عبر HTTPS بين الهاتف والكمبيوتر. تبقى المحادثة وطلبات الذكاء الاصطناعي تستخدم Groq حسب اختيارك؛ قد ترسل مهام الذكاء الاصطناعي نصوص الواجهة المرئية إليه. يبقى الكمبيوتر شغالاً والمساعد مفتوحاً وغير مقفل. لا يتجاوز التحكم شاشة قفل Windows أو UAC، ولا يوقظ جهازاً نائماً وحده.

## ما تم التحقق منه

- Python: نجح 292 اختباراً؛ تخطّى Linux اختبار RichEdit الخاص بـWindows. ينفّذه workflow على Windows قبل بناء المثبّت.
- Android: نجح 14 اختباراً، وبناء Debug وRelease وفحص lint لكليهما.
- QR: نجح فك بيانات الرمز الناتج من مولّد البرنامج باستخدام قارئ Android الفعلي.
- نجح فحص بدء المصدر وصياغة JavaScript للإضافة.

لا تعادل هذه الاختبارات تجربة حساب Facebook أو الميكروفون أو محرر Windows أو الراوتر الفعلي عندك. بعد تثبيت النسختين ابدأ بفتح Facebook، ثم اكتشاف الجروبات، ثم قراءة رابط منشور؛ اختبر المعاينة قبل أي نشر حقيقي.
