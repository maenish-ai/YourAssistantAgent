# اختيار الصوت وتفادي تكرار الخطأ — تحديث تطويري

في تطبيق Android، اضغط «تجربة واختيار صوت عربي»، ثم اضغط اسم الصوت لسماع عينة وحفظه. يعرض التطبيق الأصوات التي يتيحها محرك الهاتف الحالي فقط، ويذكر إذا كان الصوت يحتاج الإنترنت. إذا لم تظهر أصوات عربية، افتح «إعدادات محرك صوت الهاتف» وثبّت أو اختر صوتاً عربياً في نظام الهاتف. يختلف توفر الأصوات وجودتها وجنسها بين المحركات والأجهزة؛ لم يُختبر صوت بشري معين أو حساب سحابي في هذا التحديث.

عند فشل خطوة الكمبيوتر مرتين متتاليتين بنفس المدخلات، يتوقف الوكيل بدلاً من تكرارها للمرة الثالثة، ويعرض آخر خطأ. هذا لا يضمن أن جميع الأعمال مكتملة أو أن الأخطاء تصلح ذاتياً؛ يجب مراجعة النتائج والصلاحيات. التأكد من أثر أي عملية خارجية يبقى مطلوباً.

يتطلب التحديث بناء نسختي Windows وAndroid من المصدر. نسخة APK التجريبية الموقعة بمفتاح Debug قد لا تُحدّث التطبيق القديم بسبب اختلاف التوقيع. لا يُختبر الجهاز الفعلي أو الاتصال خارج المنزل تلقائياً بمجرد نجاح البناء.

التحقق المحلي: نجح بناء Android Debug و34 اختبار Android آلياً، وظهر في Lint صفر أخطاء و21 تحذيراً. نجح اختبار Python الشامل (517 نجاحاً، 8 متجاوزة)، ثم نجح 48 اختباراً مركزاً بعد تعديل رسالة الخطأ. لم تجر تجربة فعلية على هاتف أو Windows أو اتصال خارجي.
