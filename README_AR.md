# Your Assistant Agent v1.3.0 — Chat First + Encrypted Cloud Backup

هذه النسخة تحول البرنامج من مجموعة تبويبات وإعدادات إلى واجهة **محادثة رئيسية** أقرب لفكرة ChatGPT، مع إبقاء الأدوات المتقدمة في طبقة ثانية.

## ما الجديد

### 1) واجهة Chat First
- أول تبويب هو **المحادثة**.
- اكتب طلبك بشكل طبيعي بالعربية أو الإنجليزية.
- الوكيل يستخدم الـLocal AI المدمج ثم يحول الكلام إلى خطة قابلة للمراجعة.
- إذا كانت الخطة حملة Facebook، يعرض:
  - المنشور المطلوب.
  - الموعد.
  - شرط الجروبات.
  - **عدد الجروبات المطابقة فعليًا**.
  - أمثلة من أسماء الجروبات.
  - الفاصل بين المشاركات.
  - نافذة منع التكرار.
- لن تُحفظ الخطة إلا بعد الضغط على **وافق ونفّذ الجدولة** أو قول أمر موافقة واضح.
- المتابعة الحوارية مدعومة؛ إذا كانت هناك خطة معلقة، يمكن تعديلها بكلام طبيعي بدل إعادة كتابة كل شيء.

### 2) الذاكرة والمحادثات
- المحادثات تُحفظ محليًا في قاعدة بيانات البرنامج.
- اسم المستخدم واسم النشاط وصفحة Facebook الافتراضية تُستخدم كسياق إضافي للوكيل.
- الجروبات المحفوظة تُرسل أسماؤها للعقل المحلي كسياق حتى يفهم طلبات مثل "الجروبات اللي إلها علاقة بخلدة" بشكل أفضل.
- يمكن بدء محادثة جديدة ومسح سجل المحادثة المحلي من الواجهة.

### 3) المرفقات
- يمكن إرفاق صور وملفات بالمحادثة.
- تُنسخ إلى مجلد بيانات البرنامج وتدخل ضمن النسخ الاحتياطي.
- **مهم:** أداة Facebook التنفيذية الحالية تشارك منشورًا موجودًا من صفحة Facebook. لا يتم إنشاء منشور Facebook جديد من الصور المرفقة تلقائيًا حتى يتم إضافة Composer مخصص وآمن؛ البرنامج لا ينفذ طريقة مختلفة بصمت.

### 4) Onboarding تلقائي لفيسبوك
- بعد ربط Facebook والتحقق من الجلسة، إذا لم تكن هناك جروبات محفوظة، يبدأ اكتشاف الجروبات تلقائيًا مرة واحدة.
- تبقى أزرار الربط وتحديث الجروبات موجودة أعلى شاشة المحادثة.
- جلسة Facebook وتحديات الأمان تبقى يدوية؛ لا يوجد CAPTCHA bypass.

### 5) Activity / Settings / Advanced
الواجهة الرئيسية الآن 4 طبقات فقط:
1. **Chat** — المحادثة اليومية مع الوكيل.
2. **Activity** — حالة Facebook والطوابير والمواعيد.
3. **Settings** — الإعدادات والنسخ الاحتياطي وWake/Sleep وغيرها.
4. **Advanced** — الجروبات، الحملات، Smart Agent القديم، GitHub Deployment، WhatsApp، Audit Log.

### 6) نسخ احتياطي مجاني عبر Google Drive
لا يحتاج البرنامج إلى خادم سحابي مدفوع. استخدم **Google Drive for desktop** وسجل الدخول بحساب Gmail نفسه، ثم اختر مجلدًا متزامنًا مع Drive من Settings > Google Drive & Backup.

يحفظ البرنامج ملف `.yaa` مشفرًا بـ **AES-256-GCM** ويشمل:
- قاعدة بيانات البرنامج.
- سجل المحادثة وذاكرة العمل.
- Smart Rules والجداول.
- قائمة الجروبات ونتائج المشاركة.
- الإعدادات.
- المرفقات.
- Telegram/GitHub/WhatsApp/API secrets بعد تحويلها إلى نسخة محمولة داخل الحزمة المشفرة.

لا يتم نسخ Facebook browser profile أو cookies. على جهاز جديد تسجل دخول Facebook يدويًا مرة واحدة.

### 7) Recovery Key
- أول Backup ينشئ مفتاح استعادة 256-bit.
- يتم حفظه محليًا عبر Windows DPAPI.
- من Settings اضغط **مفتاح الاستعادة** لعرضه ونسخه.
- خزنه خارج اللابتوب. بدون هذا المفتاح لا يمكن فك النسخة المشفرة على جهاز جديد.

### 8) استعادة على جهاز جديد
1. ثبّت Your Assistant Agent على اللابتوب الجديد.
2. ثبّت Google Drive for desktop وسجل الدخول بنفس Gmail.
3. افتح Settings > Google Drive & Backup.
4. اضغط Restore واختر `YourAssistantAgent-latest.yaa` أو نسخة بتاريخ معين.
5. أدخل Recovery Key.
6. البرنامج يستعيد البيانات ويعيد التشغيل.
7. سجّل دخول Facebook يدويًا مرة واحدة على الجهاز الجديد.

### 9) Local AI
يبقى Dual Local Brain من v1.2.0:
- Qwen3-0.6B — عام.
- RightNow-Arabic-0.5B-Turbo — عربي.
- Auto يختار نموذجًا واحدًا فقط في كل مرة لتقليل استهلاك RAM على أجهزة 4GB.
- GitHub Actions تنزل ملفات Local AI أثناء Build وتضعها داخل Windows Setup النهائي.

## الأمان
- التنفيذ الحساس لا يحصل بمجرد ذكره في الكلام.
- خطط الحملات تحتاج مراجعة وموافقة.
- `Pending Admin Approval` ليس Failure ولا يعاد نشر نفس البوست بسببه.
- GitHub Commit + Push لا يزال يحتاج موافقة صريحة ولا يستخدم Force Push.
- النسخ السحابية مشفرة قبل وصولها إلى مجلد Google Drive.

## بناء Windows Setup
ارفع المشروع إلى GitHub ثم شغّل Workflow:
`.github/workflows/windows-build.yml`

الـWorkflow:
1. يثبت المتطلبات.
2. يشغل الاختبارات.
3. ينزل Dual Local AI ويتحقق منه.
4. ينزل Playwright Chromium fallback.
5. يبني التطبيق بـPyInstaller.
6. ينشئ Windows Setup بـInno Setup.
7. يرفع Setup فقط كـGitHub Artifact.
