# Your Assistant Agent Browser Bridge v2

This optional extension connects **the normal browser you already use** to Your Assistant Agent through `127.0.0.1:8765` only.

It supports an allow-listed command channel for opening pages and interacting with the active tab. It does **not** bypass CAPTCHA, security checkpoints, or browser permission prompts. Sensitive final actions remain subject to the app's approval policy.

For development in Chrome/Edge: open the extensions page, enable Developer Mode, choose **Load unpacked**, and select this `browser_extension` folder.
