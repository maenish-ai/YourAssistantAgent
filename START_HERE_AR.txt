Your Assistant Agent v0.7.0 — Smart Agent

هذه الملفات جاهزة للرفع فوق مستودع v0.6.4 الحالي.

1) فك ضغط Patch v0.7.0.
2) انسخ محتوياته إلى جذر مشروع GitHub الحالي مع Replace.
3) تأكد أن المجلد your_assistant_agent وinstaller وtests في أماكنها الصحيحة.
4) Commit ثم Push.
5) افتح GitHub > Actions.
6) Workflow يشغّل الاختبارات ثم يبني Windows Setup فقط.

بعد التثبيت:
- تحقق من Facebook Connected.
- اكتشف الجروبات أو أضف جروب اختبار.
- افتح تبويب «الوكيل الذكي».
- ضع رابط صفحة المصدر.
- اكتب الأمر، Preview، ثم Approve.

Telegram Remote اختياري ويحتاج Bot Token من @BotFather وTelegram User ID الخاص بك.
